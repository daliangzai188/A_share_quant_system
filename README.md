# 四、A股交易规则必须考虑

所有策略、回测、模拟交易、实盘交易必须考虑中国 A股市场规则：

## 1. T+1

```text
今天买入，今天不能卖出。
今天买入的股票，最早下一个交易日才能卖出。
```

回测和模拟交易中，如果当天买入后当天触发卖出条件，不能直接卖出，必须记录为无法卖出。

## 2. 涨跌停

必须区分：

```text
普通股票：一般10%
ST股票：一般5%
创业板 / 科创板：一般20%
北交所：单独规则
```

回测中不能假设：

```text
涨停价一定可以买入
跌停价一定可以卖出
```

## 3. 涨停买不到

强势龙头股经常出现：

```text
一字涨停
开盘秒板
封单巨大
排队买不到
```

因此，所有涨停板策略必须经过成交概率模型过滤。

## 4. 跌停卖不出

如果股票跌停，不能默认按跌停价成交。

模拟盘和回测必须处理：

```text
跌停无法卖出
停牌无法卖出
流动性不足无法卖出
```

## 5. 交易时间

系统必须识别：

```text
9:15-9:25 集合竞价
9:30-11:30 上午交易
13:00-15:00 下午交易
非交易时间不下单
节假日不下单
停牌日不下单
```

## 6. 费用

回测必须扣除：

```text
佣金
印花税
过户费
最低佣金
滑点
```

## 7. 股票状态

必须识别和过滤：

```text
ST
*ST
退市整理
停牌
新股上市初期
一字板
炸板
尾盘偷袭涨停
流动性极差
```

# 六、数据精准原则

数据是整个系统的地基，数据不准，后续所有统计全部作废。

## 1. 复权问题

股票有分红、送股、配股，不复权的历史价格不适合直接计算历史收益。

原则：

```text
所有价格数据优先使用前复权。
收益率计算必须基于前复权价格。
```

## 2. 退市股票

不能只拉当前仍在交易的股票。

如果忽略退市股，会产生幸存者偏差，导致回测胜率虚高。

原则：

```text
历史数据尽量包含退市股票。
至少要在报告中说明是否包含退市股。
```

## 3. 涨停时间精度

涨停时间很关键。

必须采集：

```text
first_time：首次涨停时间
last_time：最后涨停时间
open_times：炸板次数
limit_times：连板天数
fd_amount：封单金额
```

因为：

```text
9:30开盘涨停
10:30盘中涨停
14:50尾盘涨停
```

这三种信号完全不同。

## 4. 封单数据口径

历史数据通常只能拿到收盘封单量。

实盘可以通过 Level-2 获取实时封单量。

原则：

```text
历史统计使用收盘封单量。
实盘使用实时 Level-2 封单量。
两者不能混用。
报告中必须说明口径。
```

# 八、成交概率模型

这是本项目最核心的模块之一。

A股龙头战法最大的问题不是股票涨不涨，而是能不能买到。

加密市场是：

```text
价格到了，基本可以成交。
```

A股龙头股是：

```text
涨停了，但可能根本买不到。
```

所以不能直接统计所有涨停股次日收益。

必须先判断：

```text
历史上这类票能不能买到？
实盘时这类票排队能不能成交？
```

---

## 1. 核心公式

```text
能否成交 = 预估今日涨停板总换手量 > 你前面的封单量 + 你的下单量

预估今日涨停板总换手金额 = 流通市值 × 历史同类型涨停板换手率
```

---

## 2. 涨停板分类维度

不同类型涨停板换手率差异极大，必须分类统计。

### 维度一：连板天数

```text
一板：首次涨停，换手率通常最高，最容易成交
二板：封单变厚，换手率下降
三板：进一步下降
四板及以上：一字板概率高，换手率极低，通常很难买到
```

### 维度二：板型

```text
一字板：全天未开板，换手率极低，几乎买不到
T字板：开过一次，换手率中等，有机会成交
多次开合板：换手率较高，较容易成交
尾盘板：强度较弱，但成交机会可能更高
```

### 维度三：首次涨停时间

```text
9:25-9:31：开盘即涨停，强势但难买
10:00-14:00：盘中涨停，中等
14:30以后：尾盘涨停，弱势但成交可能较高
```

### 维度四：市场情绪

```text
极强行情：涨停数量 > 150
强行情：涨停数量 100-150
中性行情：涨停数量 50-100
弱行情：涨停数量 < 50
```

市场越强，封单越厚，不一定越容易成交。

---

## 3. 换手率查询表

必须建立如下查询表：

```text
连板天数
板型
首次涨停时间区间
市场情绪区间
样本数
换手率均值
换手率中位数
换手率25分位
换手率30分位
换手率75分位
最大换手率
最小换手率
```

默认用悲观估计：

```text
优先使用换手率25分位数。
宁可少买，也不要高估成交概率。
```

---

## 4. 实盘成交概率计算流程

```text
Step 1：识别股票类型
  今天是几板？
  是一字板、T字板还是多次开板？
  首次涨停时间是什么时候？
  当前市场情绪如何？

Step 2：查历史换手率表
  根据类型查对应换手率25分位。

Step 3：计算预估成交空间
  流通市值 × 悲观换手率 = 今日预估总成交金额。

Step 4：读取实时封单金额
  Level-2中当前排在前面的封单金额是多少？

Step 5：计算可成交空间
  可成交空间 = 预估总成交金额 - 当前封单金额。

Step 6：计算成交概率
  成交概率 = 可成交空间 / 计划买入金额。

Step 7：执行决策
  成交概率 > 80%：允许正常仓位
  成交概率 50%-80%：降低仓位
  成交概率 < 50%：放弃
```

---

## 5. 三种买入方式

### 方式一：集合竞价买入

```text
适合：提前预判次日高开或涨停的龙头。
优点：成交确定性较高。
缺点：需要更强的预判能力。
```

### 方式二：涨停板排队

```text
适合：涨停后确认强度再排队。
优点：确定性高。
缺点：强势票可能买不到。
```

### 方式三：开板回封买入

```text
适合：涨停板打开瞬间买入。
优点：成交概率高。
缺点：风险更大，可能炸板失败。
```

第一版系统优先做：

```text
T日收盘后选股
T+1集合竞价或开盘后固定时间买入
T+2卖出
```

暂时不要一开始就做复杂盘中 Level-2 高频执行。

# 九、统计分析不失真原则

最核心原则：

```text
统计什么，就要保证什么能在实盘中真实发生。
买不到的票，从第一步就不应该进入收益统计。
```

## 1. 错误做法

```text
统计所有涨停股的次日涨跌幅，然后算平均收益。
```

问题：

```text
很多涨停股根本买不到。
这些票进入统计，会让胜率和收益虚高。
```

## 2. 正确做法

先用成交概率过滤：

```text
换手率足够
炸板次数大于0
非一字板
或虽然一字板但换手率达到成交条件
```

然后只统计：

```text
历史上实际有机会买到的股票。
```

# 十、第一版交易事件定义

第一版必须固定口径，避免统计混乱。

推荐主口径：

```text
T日收盘后确定候选股票
T+1集合竞价或开盘后固定时间买入
T+2收盘卖出
```

必须同步固定：

```text
选股时点：T日收盘后
买入时点：T+1集合竞价 / 开盘价 / 开盘后5分钟均价，三选一
卖出时点：T+2收盘
收益定义：前复权价格计算净收益
成交判定：涨停买不到不能记为买入成功
费用计算：扣除佣金、印花税、过户费、滑点
```

禁止在同一份统计里混用不同口径。

如果要切换口径，必须新建方案：

```text
方案A：T+1开盘买入，T+2收盘卖出
方案B：T+1集合竞价买入，T+2收盘卖出
方案C：T日开板买入，T+1卖出
```

每个方案单独统计，不能混在一起。

# 十一、核心因子体系

## 1. 有效因子标准

只有同时满足两个条件，才算有效因子：

```text
因子值高的股票，买到概率也高。
买到之后，收益显著高于平均。
```

如果一个因子只能选出涨得好的股票，但买不到，则不能用于实盘。

# 十五、执行阶段顺序

## 第一阶段：数据收集

目标：

```text
把2019年至今所有需要的数据保存到本地。
```

要求：

```text
原始数据落地本地
不做策略分析
数据源异常记录日志
支持断点续传
支持重复运行
优先使用Tushare Pro
所有价格优先前复权
尽量包含退市股票
```

---

## 第二阶段：换手率基础统计

这是必须先做的阶段。

目标：

```text
建立 连板天数 × 板型 × 首次涨停时间 × 市场情绪 的换手率查询表。
```

这个阶段必须早于因子统计。

原因：

```text
如果不先判断历史上能不能买到，后面统计次日收益会严重失真。
```

---

## 第三阶段：成交概率验证

目标：

```text
验证换手率模型是否能合理预测涨停板成交概率。
```

验证字段：

```text
历史换手率
炸板次数
封单金额
流通市值
连板天数
首次涨停时间
市场情绪
```

不要只看平均值，要看分位数。

---

## 第四阶段：因子统计

目标：

```text
只基于历史上实际能买到的股票，统计因子有效性。
```

必须统计：

```text
样本数
胜率
平均收益
中位数收益
总收益
最大回撤
盈亏比
最大单笔亏损
最大单笔盈利
连续亏损次数
```

---

## 第五阶段：最优组合

目标：

```text
找出最优因子组合和过滤条件。
```

要求：

```text
训练集和测试集分开
不要过拟合
不要只看总收益
必须看最大回撤和样本数
```

---

## 第六阶段：模拟实盘

目标：

```text
在不接真实资金的情况下，模拟完整交易流程。
```

必须验证：

```text
选股是否正常
买入信号是否正常
卖出信号是否正常
T+1是否正确
涨停买不到是否正确处理
跌停卖不出是否正确处理
风控是否生效
日志是否完整
结果是否可复盘
```

---

## 第七阶段：小资金实盘

实盘必须最后做。

实盘前必须完成：

```text
数据完整性验证
回测验证
样本外验证
模拟盘验证
风控测试
异常处理测试
日志复盘测试
```
