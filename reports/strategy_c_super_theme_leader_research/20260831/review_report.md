# C策略“超级板块龙头”研究报告

研究日期：2026-09-15  
研究截止日：2026-08-31  
研究窗口：2023-09-01～2026-08-31（最近三年，`action_date`口径）  
研究协议：`STRICT_DISCOVERY`，仅研究，不自动修改正式配置

## 1. 研究问题

当前C有三类逻辑分支：核心承接、原强势龙头、30～50只涨停收益扩展；配置中因为第2类按市场跌停环境拆成多个 profile，所以实际有6个可执行 profile。现有“龙头”主要是全市场龙头排名，`segment_market_leader_rank`是沪深主板、创业板等市场分段排名，都不等同于“强势板块里的板块龙头”。

本轮新增研究使用已有的板块字段：

- `theme_name`：个股所属板块；
- `theme_heat_rank`：板块热度排名；
- `theme_leader_rank`：个股在所属板块内的龙头排名；
- `theme_limit_count`：板块当日涨停数量；
- `theme_is_mainline`：板块是否处于主线标记。

数据审计：月度严格特征池共76,016行，覆盖2020-01-03～2026-08-31；`theme_data_available=True`为100%，本轮未使用缺失板块数据放行候选。

## 2. 冻结的比较口径

- 正式C及A、E、D全部冻结，组合腿序固定为`A>C>E>D`；
- C入场为T+1开盘，分支退出沿用正式C的T+3收盘；
- 费用、滑点、T+1、涨停买不到、跌停卖不出、资金占用和单票仓位全部沿用当前正式回放；
- 先按信号日冻结计划，再按真实`action_date`回放，不按信号日同日重排；
- 新支线只有在C独立复利和固定A>C>E>D组合复利都提高，且样本与回撤门槛通过后，才有资格进入下一轮认证。

按当前新增支线质量门槛（至少12笔、胜率至少65%、平均每笔至少4.5%、中位数为正，并且替换后固定组合复利提高），以上候选均未通过：前者收益和回撤不合格，后者样本不足且平均/中位收益不足；即使C总复利偶尔提高，也没有转化为组合收益提高。

## 6. 研究结论

本轮没有找到可以认证为C第4支线的“超级板块龙头”规则。当前数据支持的结论是：

1. “板块内排名第1”单独使用过宽，交易数量上升但回撤显著扩大；
2. 加入板块热度、板块涨停数量和多次开板可以改善可执行性，但样本量迅速下降；
3. 在固定`A>C>E>D`组合中，新支线会与A、E、D争夺资金，C独立收益改善不代表组合改善；
4. 现有板块字段可以用于后续研究，但目前不允许写入实盘C配置，也不改变当前三类分支和六个profile。

下一轮若继续研究，应先增加独立的板块分类数据质量审计（行业/概念口径、板块成分变更、同一股票多板块归属），再用完整三年滚动窗口重新生成候选；在获得足够的样本外成交记录前，保持研究模式和小资金/模拟盘验证。
