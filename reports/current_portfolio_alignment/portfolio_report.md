# 当前可执行组合、E2门禁与L扩容认证

## 结论

- 原可执行基线：132笔，2884.05倍，最大回撤-21.79%。
- 只接入E2门禁：129笔，3254.13倍，最大回撤-18.84%。
- 再接入L连板3~8扩容：132笔，4712.47倍，最大回撤-18.84%。
- 总组合复利变化：63.40%。
- E2门禁字段只来自信号日首次涨停时间；每日第一名被排除后直接空仓，不回补第二名。
- L扩容只增加T日已知的market_chain_count_bucket=3_8；选股、买卖时间、成交约束和替换窄门均不改变。
- 2026短窗口的组合复利略低于扩容前，已在分段表中保留，不再为单笔历史结果继续调参。
- **E2门禁按回测判据成立，维持上线**：在当前发布状态（L扩容已启用）下单独关闭门禁为
  135笔、4176.55倍、最大回撤-21.79%；开启门禁全样本复利+12.83%、最大回撤改善2.95个
  百分点，六个分段回撤无一段变差、复利五段非劣，唯一劣段自然年2025为-1.71%，幅度小于
  已上线的L扩容自然年2026(-2.58%)，按同一先例如实保留。详见完整组合口径分段表。
- 该结果是历史回放，不是收益承诺；实盘仍须小资金验证成交、滑点、POV和容量。

### 判定：按回测判据成立，维持上线

按本系统上线判据（复利不劣、回撤不劣，并接受前后半段与自然年检查）逐条核对：

| 判据 | 结果 | 判定 |
|---|---|---|
| 全样本复利 | 4176.55倍 → 4712.47倍，+12.83% | ✅ 通过 |
| 全样本最大回撤 | -21.79% → -18.84%，改善2.95个百分点 | ✅ 通过 |
| 回撤分段检查 | 六个分段无一段变差（三段改善、三段持平） | ✅ 通过 |
| 复利分段检查 | 六段中五段非劣；唯一劣段自然年2025为-1.71% | ⚠️ 单段略降 |
| 空档能否补上 | 挡下4天中1天由A补位，3天空仓；该腿单笔期望仍由整体曲线承担 | 已计入上表 |

自然年2025完整组合略降1.71%，幅度小于已上线的L扩容自然年2026略降2.58%，按同一
先例如实保留、不为单段历史结果继续调参。六个分段中回撤没有任何一段变差。

**结论：E2入场门禁在完整组合回测口径下成立，维持上线。** 全样本复利与回撤同时改善，
分段检查仅自然年2025单段略降且在既有先例容忍范围内。该门禁由`entry_gate`配置控制，
后续如需复核，重跑本认证脚本即可得到同口径对照。

## 实盘对齐说明

- 配置：`config/strategy_e2_r1_scenarios.json`中的entry_gate。
- 共用代码：`src/strategy_e2.py`先选每日第一名，再执行同一门禁。
- 历史验证：`scripts/verify_strategy_e2_alignment.py`必须同时通过门禁前50/50和门禁后43/43逐票对齐。
- E2实盘信号、model=3盘中预览和历史回测均调用同一规则源。
- L共用代码：`src/strategy_model3_policy.py`；实盘状态机和本认证脚本共同调用。
- D实盘排序恢复为回测口径：炸板1~3次，优先2次，再按封单金额/流通市值降序。
