# 策略E2：无前视、单账户R1与入场门禁实盘对齐版

## 一、最终执行标准

自2026-08-03起，E2只执行以下口径：

- 无前视：选股不得使用次日是否成交、退出是否成交、未来价格或未来收益；
- 单账户：上一笔E2未到退出日时，不允许复用同一笔资金开下一笔；
- 实盘与回测共用 `src/strategy_e2.py`，禁止研究脚本和实盘脚本各写一套筛选；
- 每日第一名在13:30~14:30首次涨停时当日空仓，禁止回补第二名；
- 目标仓位82.5%，累计实际成交额仍受80%验收下限和85%单票硬顶约束；
- 关键字段或成交可靠性数据缺失时拒绝生成E2信号，不退回旧策略。

## 二、为什么不再使用12.028倍

旧62笔/12.028倍仅保留审计，不能作为实盘目标，原因包括：

1. 研究候选先用 `buy_executed`、`sell_executed` 过滤，信号日无法知道这些未来结果；
2. 部分交易在上一笔E2仍占用资金时又开新仓，单账户无法同时使用同一笔资金；
3. 旧口径混合T+2/T+3退出，但原实盘固定T+2，规则不一致。

若把上述不可实现部分写进实盘，只会制造虚高回测，不能提高真实收益。

## 三、唯一规则源

| 文件 | 职责 |
|---|---|
| `config/strategy_e2_r1_scenarios.json` | 固化40条R1场景、入场门禁、T+2/T+3退出规则和锁定指标 |
| `src/strategy_e2.py` | 解析规则、禁止前视字段、构造R1候选、选每日第一名并执行无回补门禁 |
| `scripts/run_strategy_e2_signal.py` | 检查账户空闲状态，调用唯一规则源并生成次日实盘信号 |
| `src/combined_live_engine.py` | 把E2信号转成组合计划单，并按信号退出偏移登记T+2/T+3到期日 |
| `scripts/verify_strategy_e2_alignment.py` | 同时复核门禁前50笔和门禁后43笔逐票一致 |
| `scripts/certify_current_executable_portfolio.py` | 把E2放回A/C/D/L逐日资金曲线，验证单腿与总组合同时改善 |

## 四、选股与退出流程

```text
T日收盘完整涨停池
  → 完整数据/非ST/成交可靠性过滤
  → 40条R1规则分别筛选并取当日第一名
  → 40条结果合并，同票按scenario_rank去重
  → 只保留segment_retreat_state_bucket=neutral
  → 按circ_mv升序取第一只
  → 若第一只first_time_detail_bucket=1330_1430，当日空仓
  → 不回补同日第二只
  → T+1集合竞价与现有POV开仓
  → 按命中规则在T+2或T+3到期日退出
```

同一排序值并列时，以 `ts_code` 升序作为稳定末位键，保证Windows实盘与Mac回放选中同一只股票。

## 五、成交与资金风控

E2的候选选择和下单执行分层：

- 候选层必须通过 `allow_buy_reliable`、`is_fill_score_reliable`、`limit_data_quality=full` 和 `strategy_compatible=true`；
- 09:20集合竞价预挂和09:30至10:30 POV沿用全系统现有框架；
- 09:20开仓前总资产快照的82.5%是累计实际成交额目标；
- 累计实际成交额和最坏委托金额均不得超过总资产85%；
- 使用QMT真实可用余额并保留现金缓冲，不生成资金不足废单；
- 价格超过开盘价2%、涨停、现金不足或不足一手时停止追单；
- 有旧策略仓未实际清空时取消新开仓，不做尾盘衔接买入。

## 六、量比缺失处理

R1有规则依赖 `volume_ratio_bucket`。实盘打分表量比为空时：

1. 优先读取同日 `data/raw/daily_basic/{date}.csv` 的 `volume_ratio`；
2. 若数据源仍为空，在内存中按“当日成交量 ÷ 前5个交易日日均成交量”计算；
3. 不改写原始文件；仍无法计算时fail-closed，E2当日不出信号。

其他任一R1关键字段整列为空时同样拒绝出信号，不能静默跳过部分规则。

## 七、运行与验证

正常生成信号：

```bash
python scripts/run_strategy_e2_signal.py
```

指定日期只预览：

```bash
python scripts/run_strategy_e2_signal.py --signal-date 20260731 --dry-run
```

逐票对齐验证：

```bash
python scripts/verify_strategy_e2_alignment.py
```

正确结果必须同时满足：

- 40条规则；
- 门禁前50/50同股票、同退出规则；
- 门禁后43/43同股票、同退出规则；
- 排除7笔后不回补第二名；
- 无前视选股字段；
- 无单账户资金重叠；
- 82.5%仓位E2复利约10.221003倍；
- E2最大回撤约-11.325%；
- E2单项改动使完整组合由132笔/2884.05倍提高到129笔/3254.13倍，最大回撤由-21.79%改善至-18.84%；
- 继续接入独立验证通过的L扩容后，当前最终组合为132笔/4712.47倍，最大回撤仍为-18.84%。
