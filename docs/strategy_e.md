# 策略E：V14换手率/封单分位排序与弱区间直接空仓

## 一、正式版本

自2026-09-02起，策略E正式版本为：

```text
E_TURNOVER_FD_AMOUNT12_OPEN23_NO_TRADE_20260831_V14
```

本次只修改E，A、C、D规则以及固定腿序`A>C>E>D`、82.5%目标仓位、费用、
滑点、T+1、涨跌停和资金占用规则全部不变。E仍由T日收盘数据生成T+1计划，
按命中的R1退出规则在T+2或T+3收盘退出。

## 二、V14规则

### 1. 候选与排序

```text
T日完整涨停池
  → 数据质量、非ST、成交可靠性过滤
  → 40条R1规则分别取第一名并合并去重
  → 只保留segment_retreat_state_bucket=neutral
  → turnover_rate高值优先的同日百分位，权重50%
  → fd_amount_to_circ_mv低值优先的同日百分位，权重50%
  → 综合分降序，scenario_rank、ts_code升序打破并列
  → 冻结每日第一名
```

排序只使用信号日已知字段。`fd_amount_to_circ_mv`表示封单金额/流通市值；
较低值优先用于避免封单过度拥挤。

### 2. 每日第一名无回补门禁

V13已有四项单独门禁继续保留：

- `first_time_detail_bucket=1330_1430`；
- `market_leader_rank_bucket=rank_11_30`；
- `limit_up_count_bucket=120_180`；
- `fd_ratio_bucket=2pct_5pct`。

V14新增一条AND联合门禁：

```text
amount_ratio_bucket = 1_2_2
AND
open_times_bucket = 2_3
```

即成交额倍率处于1.2～2且炸板次数为2～3次时，E当天直接空仓：

```text
position_pct = 0
fallback_to_second_candidate = false
```

这不是两个独立排除条件。只命中其中一个条件时不触发该联合门禁；只有同时命中
才不开仓。不得改成25%仓位，也不得为了占用资金槽而开低置信度仓位。

### 3. 组合接续

- A有计划时执行A；否则检查C；
- C也无计划时检查E；
- E第一名命中门禁后视为E当日无计划，不占用资金；
- A/C/E均无静态计划时，D仍可按正式盘中规则启动；
- E不递补同日第二名。

## 六、风险说明

机械复利对交易顺序和满仓复投高度敏感，也未证明真实大资金容量。历史收益和回撤不代表
未来结果；必须继续封存2026年9月真实前向计划、委托、成交、费用、滑点和回撤，并先做
模拟及小资金验证，不能据此承诺收益或直接扩大资金。
