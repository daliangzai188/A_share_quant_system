# A5-R1 动态风控版龙头策略

## 1. 策略定位

A5-R1 是 A5 市场热度过滤龙头策略的动态风控版本。

它不改变 A5 的基础选股、排序、成交假设和卖出规则，只在 A5 发出交易信号后增加一个可复现的空仓开关。

当前版本只用于本地数据分析、回测和后续模拟盘验证。

不接实盘，不接 QMT，不做自动下单。

## 2. 继承 A5 的基础口径

A5-R1 继承 A5 的以下规则：

- 选股时点：T 日收盘后。
- 买入时点：T+1 开盘。
- 卖出时点：T+2 收盘。
- 仓位：每次使用账户总资金的 80%。
- 持仓数量：每天最多 1 只。
- 买入滑点：0.1%。
- 卖出滑点：0.1%。
- 费用：佣金、印花税、过户费。
- T+1 开盘涨停：默认买不到。
- 卖出日跌停：默认卖不出。
- 不使用盘口、Level-2、分钟 K 的未来路径数据。

## 3. A5 基础买入条件

股票必须同时满足：

```text
open_times_bucket = gte_4
volume_ratio_bucket = 2_4
amount_ratio_bucket = 2_3
```

## 4. A5 选股前过滤

以下情况不进入候选池：

```text
limit_up_count_bucket = gte_180
market_chain_count_bucket = gte_30
segment_limit_down_ratio_bucket = gte_1_5pct
market_leader_rank_bucket = rank_1
first_time_detail_bucket = 1000_1100
turnover_rate_bucket = 6_10
```

## 5. A5 选股后过滤

每日选出第一名后，如果命中以下任一条件，当天不开仓：

```text
fd_ratio_bucket = 2pct_5pct
segment_retreat_state_bucket = weak_below_3
segment_chain_count_bucket = 3_5
market_segment = bj
```

## 6. A5-R1 新增动态风控开关

A5-R1 在 A5 已经选出交易标的后，再判断以下条件：

```text
market_sentiment_level = weak
segment_market_sentiment_level = neutral
```

如果两个条件同时满足：

```text
当天跳过交易，空仓。
```

否则：

```text
保持 A5 原始 80% 仓位交易。
```

## 7. 风控开关含义

`market_sentiment_level = weak` 表示全市场涨停情绪偏弱。

`segment_market_sentiment_level = neutral` 表示个股所属分市场内部情绪不强。

两者同时出现时，说明：

- 全市场强度不足。
- 个股所在分市场也没有足够强的板块情绪支撑。
- 龙头战法容易遇到弱反抽、隔日低开、T+2 回落。

因此 A5-R1 选择空仓，而不是降仓。

- 这说明该风控开关不是单纯强化训练集收益，而是更偏向降低后期弱环境损耗。

- 对 2024 和 2025 的风险改善更明显。

## 12. 当前风险

A5-R1 仍然不是实盘结论。

还必须继续验证：

- 是否存在全样本过拟合。
- 动态风控开关在 walk-forward 中是否稳定。
- 分钟 K 路径下 T+1 开盘买入是否真实可成交。
- T+2 收盘卖出是否会受到跌停、停牌、流动性影响。
- 跳过规则是否会在未来错过真正的大龙头。
- 当前日线数据是否存在复权、退市、字段口径误差。

## 13. Walk-forward 验证

为了避免只看固定训练/测试拆分，A5-R1 增加了滚动窗口验证。

验证方式：

```text
训练窗口：历史多年
测试窗口：后续 1 年样本外
对比对象：A5 原版 vs A5-R1
```

结果：

| 窗口 | 阶段 | A5 收益 | A5-R1 收益 | 收益是否改善 | A5 回撤 | A5-R1 回撤 | 回撤是否改善 |
|---|---|---:|---:|---|---:|---:|---|
| 2020-2022 -> 2023 | 训练 | 48.69 倍 | 40.39 倍 | 否 | 27.45% | 23.33% | 是 |
| 2020-2022 -> 2023 | 样本外 | 95.59% | 113.26% | 是 | 18.10% | 13.38% | 是 |
| 2020-2023 -> 2024 | 训练 | 96.19 倍 | 87.27 倍 | 否 | 27.45% | 23.33% | 是 |
| 2020-2023 -> 2024 | 样本外 | 52.94% | 99.27% | 是 | 32.62% | 32.62% | 否 |
| 2020-2024 -> 2025 | 训练 | 147.63 倍 | 174.89 倍 | 是 | 33.98% | 32.62% | 是 |
| 2020-2024 -> 2025 | 样本外 | 93.27% | 137.77% | 是 | 32.99% | 20.69% | 是 |
| 2021-2025 -> 2026 | 训练 | 79.57 倍 | 118.51 倍 | 是 | 33.98% | 32.62% | 是 |
| 2021-2025 -> 2026 | 样本外 | 114.09% | 105.67% | 否 | 8.97% | 8.97% | 是 |

样本外统计：

```text
样本外窗口数: 4
收益改善窗口数: 3
回撤改善窗口数: 3
收益和回撤同时改善窗口数: 2
```

解释：

- A5-R1 在 2023、2024、2025 样本外改善明显。
- A5-R1 在 2026 样本外略低于 A5，但该窗口只跳过 1 笔交易，差异不大。
- A5-R1 在早期训练窗口会牺牲部分收益，这和跳过交易复盘一致。
- 该规则更像是“弱环境风险过滤”，不是无条件增强收益的因子。

## 15. 候选过滤回测

本次新增脚本 `scripts/backtest_a5_r1_filter_candidates.py`。

它不会直接修改 A5-R1 正式规则，只把剩余风险归因里暴露出来的候选因子做回测：

```text
输入：reports/a5_r1_failure_focus_group.csv
基础：A5-R1 已有交易和跳过结果
动作：额外跳过某个风险因子，或跳过两个风险因子的并集
输出：全样本、年度、训练/测试/样本外拆分
```

全样本排名前几位：

| 方案 | 成交笔数 | 额外跳过 | 胜率 | 总复利 | 最大回撤 | 最大连续亏损 | 最低年度收益 |
|---|---:|---:|---:|---:|---:|---:|---:|
| A5-R1 原始 | 323 | 0 | 59.75% | 859.10 倍 | 32.62% | 6 | +99.27% |
| 跳过 limit_times_detail_bucket = 2 | 266 | 57 | 60.15% | 342.51 倍 | 16.89% | 4 | +75.59% |
| 跳过 segment_chain_count_bucket = 5_10 | 173 | 150 | 62.43% | 107.50 倍 | 16.52% | 4 | +35.07% |
| 跳过 segment_limit_down_ratio_bucket = lt_0_1pct | 205 | 118 | 59.51% | 93.15 倍 | 20.44% | 4 | +27.75% |

结论：

- 如果只看总复利，A5-R1 原始方案仍然最好，目前没有候选过滤超过 859.10 倍。
- 如果优先看回撤控制，`跳过 limit_times_detail_bucket = 2` 是当前最值得继续验证的风险版。
- 这个风险版总复利从 859.10 倍降到 342.51 倍，但最大回撤从 32.62% 降到 16.89%，最大连续亏损从 6 降到 4。


回撤控制版暂时不作为主线策略，只保留为后续风控备选。

原因：

- A5-R1 收益优先版当前总复利最高。
- 候选过滤没有找到超过 859.10 倍的版本。
- 回撤控制版虽然把最大回撤降到 16.89%，但总复利下降到 342.51 倍，牺牲过大。
- 下一步优先验证收益优先版是否真实、可成交、不过拟合，而不是继续牺牲收益换低回撤。
