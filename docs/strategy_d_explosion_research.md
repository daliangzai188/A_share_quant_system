# 策略D爆发点、爆亏路径与结构候选研究

最后更新：2026-08-22

## 一、结论先行

本轮没有修改正式D策略。

近24个月的收盘涨停幸存者样本中，最值得继续验证的结构不是新的排序字段，而是：

```text
首次封板早于14:00
    ↓
盘中经历分歧和2～3次炸板
    ↓
14:00后出现真实回封
    ↓
在第一次满足全部门禁的回封时尝试涨停价排队
```

这条候选在当前静态历史池中同时提高了D独立策略复利和只替换D腿后的ACDE组合复利，
并且前后两个12个月都保持正复利。但当前历史D母池只包含收盘仍在涨停的股票，遗漏了
触板后失败收盘的路径，因此正式结论仍为：

```text
KEEP_CURRENT_PENDING_COMPLETE_INTRADAY_EVENT_POOL
```

也就是说，`首次封板<14:00`被提升为下一阶段唯一优先的结构候选，但还不能写入
`src/strategy_d_spec.py`或盘中监控正式BUY规则。

## 二、研究问题与锁定口径

本轮只研究三个问题：

1. D的大盈利和大亏损分别集中在哪些盘中结构和市场环境；
2. 哪种改变能同时提高D独立腿复利和当前ACDE总组合复利；
3. 当前历史数据是否足以把候选认证为真实盘中可执行策略。

所有比较锁定为：

| 项目 | 口径 |
|---|---|
| 最近24个月决策窗口 | `20240630~20260630` |
| 更早6个月只读窗口 | `20231230~20240629` |
| 组合锚点 | A、E优化后的当前正式研究底座 |
| 当前ACDE | 132笔、327.726718975489倍、最大回撤-22.9705% |
| 组合腿序 | `D>A>E>C` |
| 仓位 | 82.5%，D另保留80%成交压力折扣 |
| 交易口径 | 严格as-of、单账户逐笔机械复利 |
| 其他冻结项 | 费用、滑点、涨跌停、T+1、持仓占用和退出规则全部不变 |
| 更新门槛 | D独立复利和只替换D后的ACDE复利必须同时严格提高 |

最近24个月是唯一决策窗口；更早6个月只披露稳定性和风险，不参与更新投票。本轮结果
属于`STRICT_DISCOVERY`，不是冻结后的真正前向样本外。

## 三、当前D到底在交易什么

当前D不是普通的“收盘首板”，而是盘中分歧回封策略：

- 强势市场环境；
- 非ST首板；
- 当日炸板2～3次；
- 14:00后发生真实回封；
- 成交概率至少80%且评分可靠；
- 同日多只候选优先炸板2次，再按封单/流通市值排序；
- 信号日涨停价买入，T+2收盘退出，跌停不能卖则顺延；
- D独立扫描，但最终受单账户和`D>A>E>C`资金状态约束。

它真正希望捕捉的是：

```text
早期已有资金共识
→ 盘中产生可交易分歧
→ 尾盘重新形成共识
```

这和“14:30以后才第一次突然封板”不是同一种交易。原规则虽然要求14:00后回封，
但没有区分首次封板发生在14:00以前还是以后，这是本轮最重要的结构发现。

## 五、哪些特征更像爆发点

以下结果全部是53个“逐日第一候选”的收盘幸存者内部诊断，不是独立策略复利。

| 特征组 | 样本 | 胜率 | 平均收益 | 爆发率 | 大亏率 | 解释 |
|---|---:|---:|---:|---:|---:|---|
| 首次封板11:00～13:30 | 20 | 85.00% | +7.3617% | 20.00% | 10.00% | 最明显的结构性强组 |
| 题材主线=True | 14 | 78.57% | +5.7218% | 21.43% | 0.00% | 主线承接更强，但为收盘解释特征 |
| 题材涨停数≥11 | 10 | 80.00% | +5.5498% | 20.00% | 0.00% | 高题材聚集度更有利 |
| 市场连板数≥30 | 18 | 61.11% | +5.3924% | 16.67% | 5.56% | 高接力环境有利于大右尾 |
| 炸板2次 | 44 | 59.09% | +3.1003% | 11.36% | 9.09% | 比炸板3次更稳定 |

从机制上看，D的爆发不是简单来自“越晚越稳”，而更像来自：午后之前已经证明强度，
盘中分歧释放筹码，尾盘回封时又处于强市场、强主线和高接力环境。

题材主线、题材涨停数和市场连板数目前主要是收盘口径。除非能严格重建14:00当时的
状态，否则它们只能解释爆发样本，不能直接写进盘中BUY条件。

### 为什么选14:00结构继续研究

`首次封板<14:00`不是表中最高组合倍数，但它比集中型11:30～13:30规则更稳：

- D交易仍有38笔，没有砍到20笔；
- 前后12个月分别为2.2213倍和1.3912倍；
- 旧规则后12个月为0.9431倍，候选修复了这个亏损段；
- D最大回撤由-31.6484%降至-22.1210%；
- ACDE最大回撤保持-22.9705%，组合复利提高到403.4070倍；
- 相对旧规则改变18个逐日第一候选，实际独立交易变化15笔，不是只改一笔交易。

集中型“炸2次且11:30～13:30”虽然静态ACDE达到420.3068倍，但后12个月只有6笔，
D复利0.8565倍。它明显依赖前12个月，属于高浓度过拟合候选，本轮拒绝落地。

### 为什么不能把14:00当成精确神奇阈值

阈值结果并不单调：放宽至14:15时组合反而降到309.7455倍，放宽至14:30又回到
337.4004倍。这说明少量日期会显著改变结果。14:00目前应被理解为一个有交易逻辑的
结构边界——“此前已有强度，之后再回封”——而不是经大量样本证明的精确最优分钟。

## 八、去极值、置信区间与替换归因

### 8.1 去除最大盈利

| 口径 | 原复利 | 去掉各自最大盈利后 | 5%/95%缩尾后 |
|---|---:|---:|---:|
| 当前D | 2.026124 | 1.394638 | 1.581732 |
| 首次封板<14:00 | 3.090295 | 2.127137 | 2.477157 |

候选和旧规则都包含同一笔+45.2795%的最大盈利。去掉最大盈利或对两端缩尾后，候选仍
明显高于旧规则，改善不完全由这一笔异常值造成。

### 8.2 统计不确定性

- 当前D平均账户收益95% bootstrap区间约为-0.2867%～+5.2315%；
- 14:00候选全窗口约为+0.8310%～+6.4271%；
- 但14:00候选后12个月只有16笔，平均收益区间约为-0.6730%～+5.3954%，仍跨零。

因此全窗口证据有所增强，但后半段样本还不足以证明稳定性。机械复利提高不能消除
小样本和多重比较风险。

### 8.3 改善从哪里来

14:00候选会在同日过滤掉尾盘才首次封板的原第一名，再由剩余股票按当前排序重选。
改善不是所有替换都赚钱，例如2026-05-07由中毅达换成狮头股份反而更差；但也出现了
2026-01-05由天际股份的-3.91%换成国晟科技的+13.71%，以及2026-06-22由中钢天源
的-6.81%换成利通电子的+8.26%。这说明过滤既改变“做不做”，也改变同日选谁，必须
用完整逐日替换审计，而不能只统计被排除股票的平均收益。

## 十、最关键的数据缺口：失败路径不在母样本里

当前历史D候选来自收盘涨停池，记录的是最终`first_time`、`last_time`和`open_times`。
真实盘中程序则在第一次满足条件的14:00后回封时尝试下单。这两者并不等价：

```text
历史静态池：当天最终收在涨停，事后知道最终last_time和最终炸板次数
真实盘中：14:00后第一次满足条件就决策，之后还可能再次炸板或收盘失败
```

在当前D出现静态候选的53个强势日中，使用日线最高价和昨日涨停池审计得到：

| 审计项 | 数值 |
|---|---:|
| 非ST、允许板块、昨日未涨停、当日最高价触及涨停 | 6092只次 |
| 触及涨停但收盘未封住 | 1569只次 |
| 存在失败触板的强势日 | 53/53日 |
| 每日失败触板中位数 | 27只 |
| 单日最多失败触板 | 55只 |
| 当前严格D收盘静态池 | 206条 |

1569只是缺失母样本的上界，不代表1569笔D失败交易。日线无法知道其中多少股票真的
炸板2～3次、多少在14:00后回封、回封时封单和排队量是多少。但这个审计足以证明：
现有收盘幸存者池没有覆盖真实盘中策略面对的完整失败分母，静态回测存在向上幸存者
偏差。

因此本轮所有特征结论只能写成“在收盘涨停幸存者内部”，不能写成“真实D打板策略
已经达到3.0903倍”。

## 十一、正式决定与下一研究项

### 本轮正式决定

| 对象 | 决定 |
|---|---|
| 当前D正式规则 | 保持不变 |
| `first_time<14:00` | 保留为唯一优先结构候选 |
| 11:00/11:30～13:30集中型规则 | 因后12个月亏损和样本过少而拒绝 |
| 市场连板、题材主线等解释特征 | 未重建14:00时点前禁止落地 |
| 新BUY发布资格 | 不改变，仍为`release_eligible=false` |

### 下一项真正需要做什么

> **2026-08-22后续状态**：该项已实施，完整母池扩展为56个D强势日、
> 6,848只次首板触板，其中1,710只次收盘失败。BaoStock 5分钟预检已回填
> 6,685只次沪深样本，但171个近似信号全部存在bar内顺序歧义，且没有
> 历史买一队列深度，因此正式D仍保持不变。详见
> [策略D完整首板触板分钟事件账本](strategy_d_intraday_event_ledger.md)。

下一项不是继续切更多阈值，而是建立“D历史盘中事件账本”：

1. 母池从所有当日最高价触及涨停的非ST首板开始，必须包含收盘失败股票；
2. 使用09:30起完整分钟线，条件允许时用逐笔或盘口快照补充；
3. 逐只记录首次封板、每次炸板、每次回封、14:00后第一可交易回封和最终收盘状态；
4. 在第一可交易回封时模拟真实排队、成交概率、14:55撤单和未成交；
5. 退出继续使用当前T+2、跌停延期、费用、滑点和82.5%仓位；
6. 先复现当前D，再比较`first_time<14:00`，最后放回当前ACDE做单腿双复利验证；
7. 完整母池通过后，候选仍须单独认证，不能由本报告直接改正式规则。

只有这一步完成，才能回答D到底是“早强—分歧—尾盘回封”的高质量策略，还是收盘
幸存者筛选出来的漂亮曲线。

## 十二、复现方式

运行：

```bash
python3 scripts/research_strategy_d_explosion_features.py
```

验证要点：

1. 日志必须先复现当前D `39笔/2.026123923592倍`；
2. 当前ACDE必须复现`132笔/327.726718975489倍`，分腿为D22/A44/E49/C17；
3. `first_before_1400`应为D 38笔/3.090294700885倍、ACDE 131笔/403.407038235174倍；
4. 失败触板审计应为6092只次，其中1569只次未收在涨停；
5. `summary.json`必须保持`formal_rule_modified=false`和`release_eligible=false`；
6. 任一正式锚点、输入哈希或严格as-of审计漂移时，脚本必须报错停止。

机器可读结果保存在`reports/strategy_d_explosion_research/summary.json`，逐规则、分组、
逐日替换和失败触板明细保存在同目录CSV文件。
