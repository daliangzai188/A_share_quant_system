最后更新：2026-08-22

## 一、结论先行

本项只建立D盘中研究底座，没有修改正式D规则。

当前24个月窗口``20240630~20260630``共有484个交易日。母池入口已从旧的56个
收盘strong日扩展到全部484日，收盘情绪只保留为事后标签，不再裁剪样本：

| 母池项目 | 只次 | 占比 |
|---|---:|---:|
| 全部非ST、允许板块、昨日未涨停、当日最高价触及涨停 | 40,336 | 100.00% |
| 收盘仍封在涨停 | 27,301 | 67.68% |
| 触板但收盘失败 | 13,035 | 32.32% |
| 旧56个strong日子集 | 6,848 | 16.98% |
| 旧严格D收盘静态候选 | 206 | 0.51% |

40,336只次覆盖全部484日且无重复``交易日|股票``键；旧6,848只次与新版strong
子集逐键完全相等。这样既保留旧研究的可复核性，也纳入very_strong、neutral、
weak及盘中强转弱日期，避免用最终收盘情绪反向挑选研究日。

付费Tushare历史一分钟已完成40,332/40,336目标，每个完整目标241根，
共9,720,012根。剩4个目标全部是2024-11-28北交所：Tushare的
``stk_mins``和``pro_bar``对现/旧代码均返0行，而相邻交易日各返241行。
这是数据商单日市场缺口，不是购买权限不足。4只中有2只是多次炸板涨停股，
对D研究有意义；因此仍保留在40,336母样本分母，全窗口重放时按缺数无信号
失败关闭，禁止删除、日线代替或插值。

旧6,848只次第一阶段已经按14:00后第一次可交易回封、14:55撤单机械
重放，它的回归结论是：


## 二、锁定口径

| 项目 | 锁定值 |
|---|---|
| 策略 | 仅D |
| 最近24个月决策窗口 | ``20240630~20260630`` |
| 市场日 | 现行D口径下56个``strong``且``strategy_compatible``日 |
| 研究母池日期 | 全部484个交易日；收盘strong/very_strong/neutral/weak仅作标签 |
| 板块 | 沪市主板、深市主板、创业板、科创板、北交所 |
| 首板代理 | 昨日不在收盘涨停池，当日触及官方涨停价 |
| 价格 | 官方``stk_limit.up_limit``，禁止自行估算 |
| 历史名称/ST | ``namechange`` as-of；当日涨停池名称；官方涨停幅反证 |
| 买入路径 | 09:30开始；14:00后第一次满足条件的真实回封 |
| 炸板 | 第一可交易回封时累计2～3次，优先2次 |
| 委托截止 | 14:55撤销未证实成交的排队单 |
| 本项修改正式规则 | 否 |

此母池覆盖的“全部”，指正式窗口全部交易日的全部合规首板触板股，而不是仅限
收盘涨停股或最终strong日。扩展研究母池不等于放宽正式D强势市场门；它是为了
用分钟路径重新构造信号时点情绪，并检查现行市场门是否遗漏爆发、能否避开爆亏。

## 三、旧56日子集为什么从6,835修正为6,848

首次构建得到6,835条，但复核时发现：13条历史事件的股票是信号日之后才
变为ST，原计算用当前ST名称回填历史，错误排除了它们。复核使用：

1. 信号日官方涨停价与昨收价的实际10%涨停幅；
2. 信号日``limit_list_d``中的当日股票名称；
3. ``stock_namechange``历史区间。

三项证据证明它们在触板当日仍是普通股票。因此正确冻结值是6,848，
不是6,835。这一修正新增13条收盘封板样本，失败收盘仍为1,710条，旧严格
D静态池仍为206条。

## 四、账本三层结构

### 4.1 完整母池

``mother_pool_full_window.csv``每行是一个``交易日|股票``触板事件，包含：

- as-of名称、ST判定证据、上市/退市信息和市场分段；
- 昨收、官方涨停价和当日OHLCV；
- 是否收盘封板、是否收盘失败；
- 历史市场情绪和旧静态D候选的对照字段。

### 4.2 分钟路径账本

``event_ledger_full_window.csv``以分钟K收盘状态重建：

```text
首次分钟收盘=涨停价       -> FIRST_SEAL
封板状态 -> 非封板状态       -> LIMIT_OPEN_BREAK
非封板状态 -> 封板状态       -> RESEAL
14:00后首次回封且累计炸2~3次 -> FIRST_ELIGIBLE_RESEAL_SIGNAL
```

如果同一分钟/5分钟bar既触及涨停又交易到涨停价下方，OHLC不能证明
先后顺序，该bar必须标记``path_ambiguous=true``，不能为了增加交易而自行猜测。

### 4.3 排队与14:55撤单

事件账本采用保守证据等级：

| 证据 | 账本状态 | 含义 |
|---|---|---|
| 信号后、14:55前价格交易到涨停价下方 | ``CONFIRMED_FILL_PRICE_TRADED_BELOW_LIMIT`` | 当时的涨停价限价单已被价格穿越，可保守认为成交 |
| 信号后一直封板，但没有历史队列深度 | ``QUEUE_FILL_UNKNOWN_NO_DEPTH_CANCEL_1455`` | 不能证明排到，14:55按未成交撤单 |
| 没有第一可交易回封 | ``NO_SIGNAL`` | 不产生委托 |

这个口径不会把“整个下午都封板”自动算成排队成交。要认证这类成交，
必须拿到下单时点的买一队列前方数量、之后涨停价成交量和真实委托股数。

## 五、为什么当前不能修改正式D

### 5.1 旧56日第一阶段一分钟重放结果

| 项目 | 数值 | 解读 |
|---|---:|---|
| 完整一分钟路径 | 6,848/6,848 | 每目标241根，09:30～15:00 |
| 第一可交易回封 | 370 | 14:00≤回封时间<14:55 |
| 其中``first_time<14:00`` | 291 | 只作路径结构诊断 |
| 信号时点炸板2次/3次 | 290/80 | 按第一可交易回封时的状态，不用收盘最终次数 |
| 收盘失败信号 | 60 | 旧收盘涨停池完全看不到这类样本 |
| 后续价格穿越涨停价 | 263 | 限价排队单可被后续板下成交证明成交 |
| 无深度、14:55按未知撤单 | 107 | 始终封板不得默认排到 |
| 存在分钟内顺序歧义的信号 | 370/370 | 仍需逐笔数据确认真实炸板次数 |
| 与旧206条静态D池重合 | 93 | 收盘静态池只覆盖盘中路径的一部分 |

一分钟与五分钟在14:55前仅共同识别78个信号，Jaccard相似度17.65%，证明
五分钟只能作近似预检。370条也不是370笔可交易交易：同日存在多个互斥候选，
107条缺队列成交证据，且所有信号仍存在至少一个分钟内先后歧义。本项不计算
正式D复利或ACDE替换复利。详细结构见
[策略D一分钟路径与爆发/爆亏研究](strategy_d_intraday_1m_research.md)。

### 5.2 正式规则仍不能修改

完整母池仅解决了收盘幸存者偏差，没有自动解决以下问题：

1. 即使是1分钟K，同一分钟内的快速开合仍不可知；
2. 全窗口40,336只次尚未生成事件重放结果，不能把旧6,848子集结论冒充全窗口；
3. OHLCV没有回封当时的买一封单、流通市值时点和队列前方数量；
4. 没有盘中全市场``ever_sealed``，无法精确还原信号时点的strong情绪代理；
5. 缺少同日多候选在信号时点的封单/流通市值，不能重建每日排名；
6. 没有每笔真实委托股数和队列消耗，不能认证D独立复利和ACDE单腿替换复利。

因此``first_time<14:00``仍只是优先结构候选，正式``src/strategy_d_spec.py``、
``scripts/monitor_strategy_d_intraday.py``和组合认证口径全部不变。
