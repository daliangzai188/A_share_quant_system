# 策略D完整首板触板分钟事件账本

最后更新：2026-08-22

## 一、结论先行

本项只建立D盘中研究底座，没有修改正式D规则。

当前24个月窗口``20240630~20260630``共有56个符合现行D历史强势市场门
的交易日。从这56日的全市场日线最高价和交易所官方涨停价出发，母池
固定为：

| 母池项目 | 只次 | 占比 |
|---|---:|---:|
| 全部非ST、允许板块、昨日未涨停、当日最高价触及涨停 | 6,848 | 100.00% |
| 收盘仍封在涨停 | 5,138 | 75.03% |
| 触板但收盘失败 | 1,710 | 24.97% |
| 旧严格D收盘静态候选 | 206 | 3.01% |

所有56个强势日都存在收盘失败的触板股。这证明旧的“收盘涨停幸存者池”
不能代表D在真实盘中面对的全部路径。

免费数据源BaoStock可以回填沪深市场不复权5分钟OHLCV，用于识别大部分
明显的封板、炸板、回封和回封后再开板。但它不能证明同一个5分钟bar内
的事件先后，也没有历史买一排队深度。因此当前结论仍是：

```text
完整触板母池：通过
5分钟路径覆盖：只作近似预检
第一可交易回封：可机械标记，但时间精度受bar影响
排队成交：仅“价格后续交易到涨停价下方”可保守确认
始终封板排队：缺买一队列深度，14:55按未知撤单
正式D规则：不变
```

## 二、锁定口径

| 项目 | 锁定值 |
|---|---|
| 策略 | 仅D |
| 最近24个月决策窗口 | ``20240630~20260630`` |
| 市场日 | 现行D口径下56个``strong``且``strategy_compatible``日 |
| 板块 | 沪市主板、深市主板、创业板、科创板、北交所 |
| 首板代理 | 昨日不在收盘涨停池，当日触及官方涨停价 |
| 价格 | 官方``stk_limit.up_limit``，禁止自行估算 |
| 历史名称/ST | ``namechange`` as-of；当日涨停池名称；官方涨停幅反证 |
| 买入路径 | 09:30开始；14:00后第一次满足条件的真实回封 |
| 炸板 | 第一可交易回封时累计2～3次，优先2次 |
| 委托截止 | 14:55撤销未证实成交的排队单 |
| 本项修改正式规则 | 否 |

此母池覆盖的“全部”，指现行D市场门内的全部首板触板股，而不是仅限收盘
涨停股。本项没有放宽强势市场门；若以后要研究改变市场情绪规则，必须新建
独立项目，不能在本账本中静默放宽。

## 三、母池为什么从6,835修正为6,848

首次构建得到6,835条，但复核时发现：13条历史事件的股票是信号日之后才
变为ST，原计算用当前ST名称回填历史，错误排除了它们。复核使用：

1. 信号日官方涨停价与昨收价的实际10%涨停幅；
2. 信号日``limit_list_d``中的当日股票名称；
3. ``stock_namechange``历史区间。

三项证据证明它们在触板当日仍是普通股票。因此正确冻结值是6,848，
不是6,835。这一修正新增13条收盘封板样本，失败收盘仍为1,710条，旧严格
D静态池仍为206条。

## 四、账本三层结构

### 4.1 完整母池

``mother_pool.csv``每行是一个``交易日|股票``触板事件，包含：

- as-of名称、ST判定证据、上市/退市信息和市场分段；
- 昨收、官方涨停价和当日OHLCV；
- 是否收盘封板、是否收盘失败；
- 历史市场情绪和旧静态D候选的对照字段。

### 4.2 分钟路径账本

``event_ledger.csv``以分钟K收盘状态重建：

```text
首次分钟收盘=涨停价       -> FIRST_SEAL
封板状态 -> 非封板状态       -> LIMIT_OPEN_BREAK
非封板状态 -> 封板状态       -> RESEAL
14:00后首次回封且累计炸2~3次 -> FIRST_ELIGIBLE_RESEAL_SIGNAL
```

如果同一分钟/5分钟bar既触及涨停又交易到涨停价下方，OHLC不能证明
先后顺序，该bar必须标记``path_ambiguous=true``，不能为了增加交易而自行猜测。

### 4.3 排队与14:55撤单

事件账本采用保守证据等级：

| 证据 | 账本状态 | 含义 |
|---|---|---|
| 信号后、14:55前价格交易到涨停价下方 | ``CONFIRMED_FILL_PRICE_TRADED_BELOW_LIMIT`` | 当时的涨停价限价单已被价格穿越，可保守认为成交 |
| 信号后一直封板，但没有历史队列深度 | ``QUEUE_FILL_UNKNOWN_NO_DEPTH_CANCEL_1455`` | 不能证明排到，14:55按未成交撤单 |
| 没有第一可交易回封 | ``NO_SIGNAL`` | 不产生委托 |

这个口径不会把“整个下午都封板”自动算成排队成交。要认证这类成交，
必须拿到下单时点的买一队列前方数量、之后涨停价成交量和真实委托股数。

## 五、为什么当前不能修改正式D

### 5.1 全量5分钟预检结果

| 项目 | 数值 | 解读 |
|---|---:|---|
| 完整5分钟文件 | 6,685/6,848 | 沪深目标全部成功，每个目标48根K |
| 分钟最高价再次确认官方涨停价 | 6,603 | 才能进入5分钟路径近似预检 |
| 分钟/日线触板不一致 | 82 | 即使48根K齐全也fail-closed，不能冒充路径可用 |
| 北交所缺失 | 163 | BaoStock不支持，明确标记而非静默丢弃 |
| 采集报错/待处理 | 0/0 | 沪深对象没有数据缺口 |
| 近似第一可交易回封 | 171 | 仅为5分钟收盘状态机械重建 |
| 其中``first_time<14:00`` | 163 | 只作路径结构诊断 |
| 信号时点炸板2次/3次 | 148/23 | 按第一可交易回封时的状态，不用收盘最终次数 |
| 收盘失败的近似信号 | 13 | 旧收盘涨停池完全看不到这类样本 |
| 后续价格穿越涨停价 | 79 | 在近似信号成立的前提下，限价排队单可被价格证明成交 |
| 无深度、14:55按未知撤单 | 92 | 始终封板不得默认排到 |
| 存在bar内顺序歧义的信号 | 171/171 | 无一笔可用5分钟K认证 |
| 与旧206条静态D池重合的近似信号 | 28 | 5分钟K无法复现大量分钟内快速开合 |

上表171条不是171笔可交易交易，79条也不是79笔已认证成交。因为每个
近似信号的前置炸板/回封顺序都有5分钟bar内歧义，它们只能说明“值得用更精细
数据重放”。本项不计算D复利或ACDE替换复利，避免把近似路径写成正式收益。

### 5.2 正式规则仍不能修改

完整母池仅解决了收盘幸存者偏差，没有自动解决以下问题：

1. 5分钟bar内可能发生多次快速炸板/回封，顺序不可知；
2. 即使是1分钟K，同一分钟内的快速开合仍不可知；
3. OHLCV没有回封当时的买一封单、流通市值时点和队列前方数量；
4. 没有盘中全市场``ever_sealed``，无法精确还原信号时点的strong情绪代理；
5. 缺少同日多候选在信号时点的封单/流通市值，不能重建每日排名；
6. 没有每笔真实委托股数和队列消耗，不能认证D独立复利和ACDE单腿替换复利。

因此``first_time<14:00``仍只是优先结构候选，正式``src/strategy_d_spec.py``、
``scripts/monitor_strategy_d_intraday.py``和组合认证口径全部不变。

## 六、运行与验证

### 6.1 生成完整母池

```bash
python3 scripts/build_strategy_d_intraday_event_ledger.py --targets-only
```

必须看到：

```text
strong=56日
触板=6848
失败收盘=1710
当前收盘静态池=206
```

### 6.2 回填BaoStock 5分钟预检数据

```bash
python3 scripts/collect_strategy_d_intraday_baostock.py --dry-run
python3 scripts/collect_strategy_d_intraday_baostock.py
```

采集器使用``target_key``断点续传，每25条保存一次状态。``ERROR``目标下次会重试，
``OK``、``EMPTY``和``UNSUPPORTED_BJ``不会重复请求。

### 6.3 生成事件账本

```bash
python3 scripts/build_strategy_d_intraday_event_ledger.py \
  --minute-bars data/research/strategy_d_intraday/minute_5m_baostock.csv \
  --data-source BAOSTOCK_5M_UNADJUSTED_APPROXIMATE
```

输出：

| 文件 | 作用 |
|---|---|
| ``data/research/strategy_d_intraday/mother_pool.csv`` | 6,848条完整触板母池 |
| ``minute_target_manifest.csv`` | 一分钟和tick/队列数据采集目标 |
| ``minute_5m_baostock.csv`` | 不复权5分钟预检数据 |
| ``event_ledger.csv`` | 每个触板目标的路径、信号、排队和撤单结果 |
| ``event_detail.csv`` | 封板/炸板/回封/信号/成交/撤单事件明细 |
| ``minute_coverage.csv`` | 逐股逐日分钟覆盖状态 |
| ``reports/strategy_d_intraday_research/summary.json`` | 机器可读总结和认证门禁 |

### 6.4 测试

```bash
python3 -m pytest -q tests/test_strategy_d_intraday_ledger.py
```

测试覆盖：第一可交易回封、2～3次炸板、价格穿越确认成交、无队列深度时
14:55撤单、不足两次炸板时无信号、盘中bar歧义、一分价差边界和BaoStock
5分钟结束标签。
