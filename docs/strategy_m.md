> 状态：**已实现，默认全关**（`strategy_m.enabled=false`、`live_order_enabled=false`）。
> 本文件同时是上线检查清单。放开实盘前请逐条核对第六节。

> **2026-08-07 M 不再是"五腿全空才兜底"**：腿序重排为 D>L>A>M>E2>C 后，M 排在
> E2 和 C **之前**，只被 D持仓 / L信号 / A计划 挡住。配套改动：
> `config.json` 的 `strategy_m.require_all_legs_idle` 由 true 改为 false、
> `run_strategy_m_signal.other_leg_has_signal` 改名为 `higher_priority_leg_has_signal`
> 并只检查 L 与 A。本文下文凡出现"五腿全空/全部无候选才触发"的表述，均为该改动
> 之前的历史口径。M 自身的 10% 回撤保护不变，仍在信号生成侧生效。

## 一、它是什么

M 是第六条腿，只做一件事：**把原本完全空仓的日子利用起来**。

历史回放显示，481 个信号日里有 **291 天（60.5%）A/C/D/E2/L 全部没有候选**，账户空转。
M 在这批日子里挑出满足条件的一小部分（两年 25 天）开仓。

**它不与任何腿竞争优先级，不替换谁，也不改变任何现有腿的规则。**

## 二、完整规则

```
触发前提（四条必须同时成立）：
  1. A/C daily ops 当日未生成计划委托
  2. E2 当日无正式信号
  3. L 当日无正式信号
  4. 账户没有任何未平仓头寸   ← 这条同时覆盖 D

自有闸门（两条）：
  5. 当日 sz_main_market_sentiment_level = weak（深市主板情绪弱）
  6. 账户当前回撤 ≤ 10%

选股：
  当日涨停池 → 数据质量/可买性/非ST 过滤 → 取流通市值最小的一只

执行：
  T+1 开盘买入，T+2 收盘卖出，仓位 82.5%
```

第 4 条为什么能覆盖 D：D 在信号日**盘中**打板买入，成交后即出现在 `positions.json`。
M 在收盘后运行，看到持仓就退出，**因此 D 天然优先于 M，不需要额外逻辑**。

## 三、优先级位置

```
①  A/C          收盘后信号，最高优先级
②  E2           A/C 无票时补位
③  D            信号日盘中打板
④  L            按 model=3 规则补位或替换
──────────────────────────────
⑤  M            以上全部无票且账户空仓时才触发
```

## 五、证据强度（必须与收益数字一起读）

### 支持它的证据

| 检验 | 结果 |
|---|---|
| 随机选票对照（500 次） | p = **0.0000**，无一次超过真实值 → "选市值最小"携带信息 |
| 随机选日对照（500 次） | p = **0.0000**；随机选日只有 4.8% 能超过基线 → "weak"条件是必需的 |
| 触发条件单调性 | weak 3.11x > strong 0.44x > neutral 0.03x，方向合理 |
| 无条件在空档日交易 | **0.07x** —— 反证空档日整体有害，筛选不可省 |
| 分年 | 2024 / 2025 / 2026 **全部改善** |
| 分半年 | 5 段中 4 升 1 平 |
| 样本外 | 3 笔全正（+2.36% / +0.23% / +5.70%） |

### ⚠️ 反对它的证据（同等重要）

| 问题 | 具体表现 |
|---|---|
| **参数邻域塌陷** | 9 种排序里只有"流通市值最小"是好的（3.11 倍），**次优仅 1.13 倍**；T+2（3.11 倍）显著优于 T+3（1.39 倍）。**单点最优、邻域塌陷是过拟合的典型指纹。** |
| **样本内挑选** | 规则是从约 1053 个候选方案中按组合复利挑出的第一名 |
| **样本外极薄** | 只有 3 笔；实盘 2026-06~07 那两个月**一次都不会触发** |
| 触发稀疏 | 两年 25 笔 ≈ 每年 13 次，攒到 20 笔需 1.5~2 年 |
| 回撤恶化 | −18.84% → −24.68%，多 5.84 个百分点 |

**结论：规则方向有证据支持，但 3.37 倍这个倍数不可作为实盘预期。**
上线后应按"期望为正、倍数远低于回测"管理预期。

### 下行风险（已量化）

| M 的真实期望 | 组合复利 | vs 基线 |
|---|---:|---:|
| 回测水平 +5.50%/笔 | 15891x | 3.37x |
| 样本外水平 +2.76%/笔 | 6987x | 1.48x |
| **完全无效 0%/笔** | **3980x** | **0.84x（−15.5%）** |
| 负期望 −3%/笔 | 2127x | 0.45x |

**下行成本是固定的 −15.5%**，来自 M 顶掉的 11 笔原有交易（机会成本），
**与仓位大小无关**——因此减仓只砍收益、不减这部分风险。赔率约 **13:1**。

## 六、上线检查清单

放开 `enabled` / `live_order_enabled` 前逐条确认：

- [ ] **净值读取可用**。M 依赖账户净值算回撤。开发机无 QMT 时会读到 0 并

## 七、设计禁忌

> **回撤保护开关只能用于 M 这类补位腿，绝不可推广到 A/C/D/E2/L。**

M 被净值门控是安全的，因为其余五腿**无条件触发**——它们在回撤中照常交易并修复净值，
M 随后自动恢复。回测中 20240902/20240911 两次暂停后，L 的 +16.41%、+8.22% 与
E2 的 +10.56% 把净值拉回新高，M 于 20241011 恢复并赚了 +17.37%。

若把该开关推广到所有腿，**回撤中将没有任何腿能创造修复净值的机会，系统会锁死在回撤里。**
