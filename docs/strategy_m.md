## 一、它是什么

M 是组合中的第三优先腿，只做一件事：**在D/A均未占用时使用符合条件的机会**。

历史回放覆盖481个信号日。当前M在账户空仓且D/A没有占用时判断。
因为M排在E/C之前，它既补充空仓日，也可能优先于下游E/C。

**它不改变其他腿的规则，当前按D>A>M>E>C>N占用单账户资金。**

## 二、完整规则

```
触发前提（三条必须同时成立）：
  1. A daily ops 当日未生成A计划
  2. 账户没有任何未平仓头寸   ← 这条同时覆盖 D
自有闸门（两条）：
  5. 当日 sz_main_market_sentiment_level = weak（深市主板情绪弱）
  6. 账户当前回撤 ≤ 10%

选股：
  当日涨停池 → 数据质量/可买性/非ST 过滤 → 取流通市值最小的一只

执行：
  T+1 开盘买入，T+2 收盘卖出，仓位 82.5%
```

第 3 条为什么能覆盖 D：D 在信号日**盘中**打板买入，成交后即出现在 `positions.json`。
M 在收盘后运行，看到持仓就退出，**因此 D 天然优先于 M，不需要额外逻辑**。

E和C不在M的上游门中：两者排在M后面，不得反向阻断M。

## 三、优先级位置

```
①  D            信号日盘中打板，时序优先
②  A            收盘后计划
③  M            D/A均未占用且账户空仓时触发
④  E            M无信号时补位
⑤  C            最后补位
⑥  N            真正最低优先级补位
```

### 当前上线判定

M提高全样本复利，但当前组合的训练半段复利下降7.49%、自然年2025下降30.67%，
因此没有通过“所有分段收益和回撤均非劣”门禁；规则又来自1053个
方案搜索、样本外仅3笔。
用户已明确接受上述风险，因此当前`live_order_enabled=true`，认证使用独立状态
`PASS_WITH_RISK_ACCEPTANCE`。这不等于统计验证通过。500次随机对照无超越样本只能写
经验p值上界`1/501=0.001996`，不能写成p=0，也不能替代多重检验和前向验证。

## 五、证据强度（必须与收益数字一起读）

### 支持它的证据

| 检验 | 结果 |
|---|---|
| 随机选票对照（500 次） | 无一次超过真实值；plus-one经验p值上界 **1/501=0.001996** → "选市值最小"携带信息 |
| 随机选日对照（500 次） | plus-one经验p值上界 **1/501=0.001996**；随机选日只有4.8%能超过基线 → "weak"条件是必需的 |
| 触发条件单调性 | weak 3.11x > strong 0.44x > neutral 0.03x，方向合理 |
| 无条件在空档日交易 | **0.07x** —— 反证空档日整体有害，筛选不可省 |
| 分年 | 2024 / 2025 / 2026 **全部改善** |
| 分半年 | 5 段中 4 升 1 平 |
| 样本外 | 3 笔全正（+2.36% / +0.23% / +5.70%） |

### ⚠️ 反对它的证据（同等重要）

| 问题 | 具体表现 |
|---|---|
| **参数邻域塌陷** | 9 种排序里只有"流通市值最小"是好的（3.11 倍），**次优仅 1.13 倍**；T+2（3.11 倍）显著优于 T+3（1.39 倍）。**单点最优、邻域塌陷是过拟合的典型指纹。** |
| **样本内挑选** | 规则是从约 1053 个候选方案中按组合复利挑出的第一名 |
| **样本外极薄** | 只有 3 笔；实盘 2026-06~07 那两个月**一次都不会触发** |
| 触发稀疏 | 两年 25 笔 ≈ 每年 13 次，攒到 20 笔需 1.5~2 年 |
| 回撤恶化 | −18.84% → −24.68%，多 5.84 个百分点 |

**结论：规则方向有证据支持，但 3.37 倍这个倍数不可作为实盘预期。**
上线后应按"期望为正、倍数远低于回测"管理预期。

## 七、设计禁忌

> **回撤保护开关只能用于 M 这类补位腿，绝不可推广到 A/C/D/E。**

M被净值门控时，其余策略仍按各自条件交易并可能修复净值，M随后自动恢复；
因此该保护不能推广成全组合停机开关。

若把该开关推广到所有腿，**回撤中将没有任何腿能创造修复净值的机会，系统会锁死在回撤里。**
