# A>C>E>D真实开仓日优先级落地记录

最后更新：2026-08-24

## 一、最终决定

当前生产组合固定为：

```text
A > C > E > D
```

这不是把四条策略的信号日候选放在一起直接排序。可执行语义是：

1. A、C、E在上一交易日收盘后生成今天的静态计划；
2. 账户空仓时按A、C、E选择唯一计划；
3. A/C正式计划保留既有依赖：A无正式候选才由C补位；
4. A/C/E三腿今天都没有计划时，才允许D从09:30启动完整盘中路径；
5. 任一策略持仓在退出日收盘后才释放，退出日不允许同账户再开新仓。

### 1.1 长期执行与优化标准

`A>C>E>D`从本次决定起作为长期组合标准。后续所有因子、阈值、排序、过滤、退出、
半年更新和单腿替换研究，都必须在该顺序下进行真实开仓日单账户回放，不再把腿序
作为普通优化变量。

固定该顺序的策略定位是：

| 顺位 | 策略 | 固定定位 |
| ---: | --- | --- |
| 1 | A | 低分段热度、中等连板环境和适中封单比例的主策略；规则较简单、T+2退出 |
| 2 | C | 强势环境与龙头形态补充；两分支OR、T+3退出，前向样本仍需继续积累 |
| 3 | E | 在A/C均无正式计划时参与静态计划裁决 |
| 4 | D | 只有A/C/E均无计划时才启动盘中回封路径 |

A放在C之前，是因为A的规则自由度较低、同窗口数据挖掘程度相对更小、持仓时间更短，
优先考虑模型稳健性和执行风险。该判断不等于A的历史尾部风险更小：当前窗口A最大
回撤和最大单笔亏损均大于C，文档和报告必须同时披露这一事实，不能用“稳妥”隐藏
实际亏损指标。

以后每个优化候选必须满足：

1. 基准和候选均使用`A>C>E>D`，并映射到真实`action_date`；
2. 按退出日收盘后释放资金，禁止资金重复占用；
3. 其他三腿和组合执行假设冻结，只替换正在研究的一腿；
4. 同时报告独立策略指标和固定顺序组合指标；
5. 其他顺序的结果只作诊断，不参与选优和发布；
6. 普通策略优化不得改变本顺序。若用户以后明确要求改变，必须建立独立的顺序版本、
   风险接受记录、严格认证、回归测试和文档更新。

## 二、为什么不用1463.912878倍

1463.912878倍来自把D和A/C/E都放在同一个`signal_date`重排。D在当天盘中决策，
A/C/E要到当天收盘后才能形成下一交易日计划；让D依据当天收盘后的候选让路会使用
未来信息，实盘无法执行。因此该结果只保留为错误口径诊断，不进入配置、认证、发布
或资金规划。

正式比较把四腿统一映射到真实`action_date`。D使用自身`signal_date`，A/C/E使用
`buy_date`，然后执行单账户逐日占仓。
