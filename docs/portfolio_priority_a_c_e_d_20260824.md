## 一、最终决定

当前生产组合固定为：

```text
A > C > E > D
```

这不是把四条策略的信号日候选放在一起直接排序。可执行语义是：

1. A、C、E在上一交易日收盘后生成今天的静态计划；
2. 账户空仓时按A、C、E选择唯一计划；
3. A/C正式计划保留既有依赖：A无正式候选才由C补位；
4. A/C/E三腿今天都没有计划时，才允许D从09:30启动完整盘中路径；
5. 任一策略持仓在退出日收盘后才释放，退出日不允许同账户再开新仓。

## 二、为什么不用1463.912878倍

1463.912878倍来自把D和A/C/E都放在同一个`signal_date`重排。D在当天盘中决策，
A/C/E要到当天收盘后才能形成下一交易日计划；让D依据当天收盘后的候选让路会使用
未来信息，实盘无法执行。因此该结果只保留为错误口径诊断，不进入配置、认证、发布
或资金规划。

正式比较把四腿统一映射到真实`action_date`。D使用自身`signal_date`，A/C/E使用
`buy_date`，然后执行单账户逐日占仓。
