# 策略D回封板条件组合系统研究

> 研究日期：2026-08-22
> 正式窗口：2024-06-30～2026-06-30
> 协议：`STRICT_DISCOVERY`
> 正式修改：否

## 一、研究目标

D的核心不是某一组固定参数，而是“首板炸开后重新封板时打板”的策略族。当前
正式D只是这个策略族中已经落地的一组条件：强情绪、首板、炸板2～3次、首次
封板不早于10:00、14:00后回封、成交概率门和T+2收盘退出。

本轮不再把当前条件当成回封板的全部，而是从完整一分钟路径中提取每一次回封，
系统组合回封时间、炸板次数、回封速度、炸板深度、量能和盘中市场情绪，回答：

1. 哪些回封条件组合自身能赚钱；
2. 哪些组合与当前正式D合并后提高D复利；
3. 哪些组合放回D>A>E>C后仍提高ACDE总复利。

所有赚钱组合都会落表，不只公布最好的一条。正式D不再称为“D6”；旧六流派
报告中的数字仅代表研究分类序号，不代表存在六个正式D策略。

## 二、数据母集和事件定义

输入继续使用全窗口首板触板母池及Tushare一分钟数据：

| 项目 | 数值 |
|---|---:|
| 首板触板股票日母池 | 40,336 |
| 完整且价格一致的一分钟路径 | 40,328 |
| 数据商空缺/跨源不一致，保留分母并fail-closed | 8 |
| 14:55前全部回封事件 | 33,821 |
| 至少发生一次回封的股票日 | 12,639 |
| 覆盖交易日 | 484 |
| 信号时炸板次数范围 | 1～27次 |

“回封”固定定义为：一分钟收盘状态从未封涨停切换为封住涨停，且此前至少发生过
一次封板和一次炸板。最终是否收涨停、后来是否盈利都不参与信号形成；13,035条
失败收盘母样本仍在完整触板分母内。

## 三、5,944条条件组合

组合只能引用下单分钟已经知道的字段：

| 条件轴 | 覆盖方式 |
|---|---|
| 回封时间 | 不限、09:30～10:00、10:01～11:30、13:00～13:59、14:00后等 |
| 炸板/回封次数 | 不限、1次、2次、3次、4次、5次以上及多个连续区间 |
| 回封速度 | 不限、1/2/5分钟内、2～5分钟、6～10分钟、11分钟以上 |
| 炸板结构 | 首封至回封时长、最后炸板收盘/最低回落深度 |
| 量能 | 信号前累计成交额、最近5分钟成交额相对前日 |
| 盘中情绪 | 当时首板触板数、仍封住数量、封住率、累计炸板事件率 |
| 市场板块 | 沪深主板、创业板/科创板 |
| 价格路径 | 开盘涨幅、信号前最低价等 |

冻结搜索共5,944条、5,459种不同的当日选择序列。其中：

- 1,680条明确不限制回封时间，由次数、速度或其他质量条件约束；
- 1,680条明确不限制炸板/回封次数，由时间、速度或其他质量条件约束；
- 700条完整时间×次数×速度结构网格；
- 108条在时间、次数和速度全部不限时使用两个不同质量维度交叉。

禁止使用的字段包括最终封板、失败收盘、信号后价格穿透、退出日、T+2收益及
未来成交结果。组合数量较多，所有结论都属于当前24个月样本内多重比较发现。

## 四、机械选择、成交和三层门禁

每条组合执行相同顺序：

```text
信号时点条件过滤
→ 当日最早回封事件
→ 同一分钟按炸板2次优先、近5分钟量能、代码稳定排序
→ 得到当日唯一挂单
→ 14:55前后续分钟价格低于涨停价才确认排队成交
→ 独立单账户T+2占仓回放
→ 与当前正式D按真实信号分钟互斥
→ 逐腿放回冻结A/E/C
```

始终封板但缺历史买一队列的订单保守记为未成交；它在14:55撤单前仍会阻断更晚
的D信号，不能事后因为没成交而倒选另一只股票。

门禁固定为：

1. 条件组合独立成交至少20笔、复利大于1、退出全部可解析；
2. 与当前正式D合并后的D复利高于2.0261239236倍；
3. ACDE总复利高于327.7267189755倍。

仓位82.5%、D成交压力折扣80%、费用、滑点、涨跌停、T+1、T+2收盘退出和
`D>A>E>C`全部不变。

## 七、收益来源与稳健性审计

独立25笔去掉最大盈利后仍为1.178038倍，去掉最大亏损后为1.442177倍，收益
并非只靠一个暴利样本。但平均收益bootstrap 95%下界为-0.8621%，样本仍不足。

## 八、正式D信号时点跨源审计

正式D的53个历史候选来自冻结涨停池静态`open_times/last_time`；一分钟K按每分钟
收盘状态重建开合。静态数据可记录分钟内瞬时炸开，而一分钟收盘可能始终封板，
两者不能强行要求事件次数相等：

| 项目 | 数值 |
|---|---:|
| 正式D候选 | 53 |
| 官方`last_time`与一分钟回封分钟精确一致 | 11 |
| 静态事件与一分钟收盘路径不能精确映射 | 42 |
| 官方最终回封时间达到或晚于14:55 | 7 |

正式2.026124倍基线按用户锁定要求原样保留，没有用分钟路径删除或替换任何正式
候选。家族内部信号仲裁优先使用官方`last_time`；7笔晚于撤单时间的记录中，2笔
使用14:55前最后一分钟回封，另外5笔保守压到14:54作为最后有效仲裁分钟。
精确名单永久保存在`summary.json`及稳健性摘要中。

这项差异说明新候选即使数学通过，也需要实盘信号定义和历史认证口径进一步统一，
不能直接把研究结果写入监控器。

## 九、正式结论

本轮证明了用户提出的核心判断：D应当被研究为回封板策略族，而不是只有当前一种
风格。确实找到了大量独立赚钱组合，并找到一组同时提高独立、合并D和ACDE复利
的早盘第一次回封候选。

但该候选暂不修改正式D，原因是：

1. 25笔样本低于50笔，平均收益bootstrap下界为负；
2. 从5,944条同窗口组合中发现，多重比较风险高；
3. 只有2条数学通过且真实成交相同，不是两个独立发现；
4. ACDE相对提升约0.97%，边界轻微变化即可失效；
5. 正式静态D与一分钟事件时点仍存在跨源差异；
6. 尚未完成更早6个月旁证和未来6个月前向样本外。

正式状态为：

```text
RESEAL_COMBINATION_CANDIDATE_FOUND_KEEP_FORMAL_D_PENDING_ROBUSTNESS_VALIDATION
```

## 十、代码、输出和复现

代码：

- `scripts/research_strategy_d_reseal_combinations.py`：提取全部回封、搜索5,944条组合、执行三层复利门禁；
- `scripts/audit_strategy_d_reseal_candidate_robustness.py`：边界、收益来源和仲裁敏感性审计；
- `tests/test_strategy_d_reseal_combinations.py`：规则空间、信号时点字段、日内先后和未知队列阻断测试。

主要输出：

- `all_reseal_signal_events.csv`：33,821个全回封事件；
- `all_combination_metrics.csv`：5,944条完整结果；
- `profitable_combinations.csv`：729条独立赚钱组合；
- `profitable_unique_daily_selections.csv`：689种去重赚钱选择；
- `triple_gate_passed_unique_combinations.csv`：2条三层通过项；
- `selected_candidate_perturbation_audit.csv`：11个相邻边界审计；
- `summary.json`、`selected_candidate_robustness_summary.json`：机器可读结论。
