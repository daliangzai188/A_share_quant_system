## 一、评估标尺（铁律：不许换尺）

当前实盘规则的后续改动，一律先在以下可执行组合标尺上逐日回放：

```
文件: reports/current_portfolio_alignment/portfolio_summary.csv
场景: current_after_e2_gate_and_l_chain_3_8_expansion
指标: 132笔 | 4,712.47x | 最大回撤-18.84% | 最大单笔亏损-16.37%
```

以下8302标尺只用于复核2026-07-24以前的历史研究，不再用于认证当前实盘：

```
文件: reports/position_overlap_audit/model3_live_candidate_8302_daily_cash_constraint.csv
指标: trade_return 列连乘 = 8,302x   |   最大回撤基准 = -18.3%
```

**为什么必须锁死**：2026-07-24 在"D 持仓要不要挡 L"上连续给出 4 个互相矛盾的结论，根因全是换标尺
（一会用 mode1 基线曲线 3,039x、一会用 8302x 文件、一会用 cash_adjusted_return 801x）。标尺一换结论就翻，
无法判断对错。锁死后这类错误结构上消失。

**8302x 的正确定位**：它是**理论对齐基准**，不是实盘可达目标。
- `trade_return` 连乘 = 8,302x = 每笔满仓的理想上界；
- `cash_adjusted_return` 连乘 = 801x = 计入衔接日现金约束后的现实值；
- 实盘还有滑点、排队买不进等执行损耗（由每晚"执行对账"单独跟踪）。

**用法**：8302只做历史相对比较；当前策略任何改动必须使用132笔逐日组合标尺，
同时验证对应单腿、完整组合、前后半段/分年方向和实盘共用规则源。

**通用教训**：
- "关注度/人气"类信号（股吧热度、搜索量、榜单）**默认负期望**，除非与涨停结构结合（那已是现有体系）；
- 外部（含其他 AI）给出的高倍数回测，先做三查：**能不能买到**（一字板）、**止损是否被改写**、**可成交子集的真实收益**。

## 八、工作方式铁律（用户明确要求）

1. **不打补丁要根治**：出事故先做同类全景审计，一次收口；修复优先"消灭特例、统一进已有机制"；
   补丁只作临时兜底且必须附根治计划。**架构手术只在非交易日做。**
2. **同口径**：任何复利/回撤对比，必须声明用哪个文件哪一列，中途不换。
3. **非劣才改**：任何改动，复利不劣、回撤不劣才准上线；原逻辑更好就不动。
4. **结论要讲清原因**：日志/推送不能只给结论（"不开仓"），必须说明为什么（"D 持仓未到期占用资金"）。
