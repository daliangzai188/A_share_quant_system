# 82.5%开仓与取消衔接执行口径（2026-08-03）

## 一、最终规则

1. 普通空仓日：计划开仓金额以总资产82.5%为目标。
2. 单票硬顶：任何一笔新开仓不得超过总资产85%。该硬顶是安全上限，不是目标仓位。
3. 取消衔接：券商仍实际持有本系统旧策略仓时，不生成、不提交任何新买单；
   今日到期、逾期和`sell_pending`都算旧仓。
4. 外部持仓：打新中签股票、可转债和人工持仓不具备本地策略身份，不触发阻断，
   但券商真实可用现金仍会约束最终委托，避免废单。
5. D接力已关闭：D按自身退出规则平仓；确认清仓后的下一个信号日才允许新开仓。
6. 集合竞价与POV：选股、09:20涨停价预挂和既有09:30~10:30 POV框架不变；
   开盘后统一按“累计实际成交额”校准仓位，不再按参考价股数推算剩余仓位。

## 二、统一定仓公式

```text
允许开仓的前提 = 券商无本系统旧策略仓

累计实际成交额目标 = min(
    总资产 × 82.5%,
    实时可用现金 - 现金缓冲,
    信号日成交额 × 退出容量上限,
    固定单笔金额上限（配置大于0时）
)

累计委托绝对硬顶 = min(
    09:20总资产快照 × 85%,
    当前QMT总资产 × 85%,
    QMT实时可用现金 - 现金缓冲,
    信号日成交额 × 退出容量上限,
    固定单笔金额上限（配置大于0时）
)
```

09:20竞价种子单股数按涨停委托价和85%硬顶向下取整到整手，因此即使整单恰好
按涨停价成交，委托金额也不会超过85%。82.5%不再用09:20参考价倒推股数。

开盘确认后的统一公式：

```text
累计实际成交额 = max(
    QMT本次新增持仓数量 × QMT成本价,
    本地已确认竞价成本 + 本线程已确认POV成本
)

POV待补金额 = 82.5%目标额 - 累计实际成交额

每片委托金额 = min(
    POV待补金额,
    85%硬顶 - 累计实际成交额,
    QMT实时可用现金 - 现金缓冲,
    本片POV流动性预算
)
```

每片股数使用该片真实委托价（最高为开盘价+2%）折算，而不是使用最新价折算；
即使该片全部按委托上限价成交也不会越过目标或85%硬顶。

原计划无须POV拆分时，09:30确认后同样建立/执行POV金额校准；原计划本来需要
POV时，竞价实际成交差额合并进POV总缺口，各片按最新剩余金额重新分配，不再
沿用盘前估算的“剩余股数”。

## 三、两层防线

- 计划层：A/C/E/M/D看到任何旧策略仓，都不生成新买入；到期卖单照常保留。
- 执行层：09:20竞价、09:24 E、09:30补单、POV恢复线程、E延迟重试和D直连
  下单前都重新读取券商持仓。即使缓存中残留旧版买单，也会被拦截。

## 四、回归验证要点

- 空仓、总资产100万元、现金充足：参考价10元时目标金额不超过82.5万元，向下整手。
- 新单金额82.6万元：总仓位校验拒绝；85.1万元同时触发85%单票硬顶。
- 今日到期A/C/E/M仓仍在：只有卖出计划，不出现BUY，D监控不启动。
- D接力：09:23只提交安全卖量；每片SELL确认实际成交后才允许对应金额的BUY，
  原有空闲现金不得被使用，10:30剩余D继续持有至原计划平仓日。
- 打新债券、打新股票或人工仓：不作为策略旧仓阻断，但可用现金仍按QMT实时值计算。
- 当日竞价部分成交：允许POV继续完成同一笔，不误判成旧仓。
- 普通100万元空仓账户：82.5万元为实际成交目标，80万元为验收下限，85万元为
  最坏委托硬顶；10cm/20cm/30cm涨停预挂均按各自涨停价验证不越85万元。
- 竞价实际成交77万元：POV只补实际差额5.5万元，并按开盘价+2%的委托上限向下
  取整；累计达到或超过82.5万元后不再补。
- 竞价残单未确认终态：POV暂停，不允许两路买单叠加。

## 五、风险说明

80%是正常资金条件下的验收下限，不是突破流动性硬顶或+2%追价保护的理由。
若涨停、价格超过开盘2%、成交量不足或退出容量硬顶低于80%，系统不强行追仓，
10:30收口并明确告警/记录原因。82.5%与取消衔接是新的实盘执行选择，历史
8302x/5604x等包含不同衔接口径，不能直接当作新规则的收益结论。扩大实盘资金前
仍应先以小资金观察成交、滑点、最大回撤和连续亏损，再决定是否提高资金规模。
