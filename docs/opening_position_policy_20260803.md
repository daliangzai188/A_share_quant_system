# 82.5%开仓与取消衔接执行口径（2026-08-03）

## 一、最终规则

1. 普通空仓日：计划开仓金额以总资产82.5%为目标。
2. 单票硬顶：任何一笔新开仓不得超过总资产85%。该硬顶是安全上限，不是目标仓位。
3. 取消衔接：券商仍实际持有本系统旧策略仓时，不生成、不提交任何新买单；
   今日到期、逾期和`sell_pending`都算旧仓。
4. 外部持仓：打新中签股票、可转债和人工持仓不具备本地策略身份，不触发阻断，
   但券商真实可用现金仍会约束最终委托，避免废单。
5. D接力例外：只保留D面对A/C/E2候选时09:23先卖的既有流程。必须先确认
   券商D持仓为零，再同步本地持仓并重新生成买入计划；D面对L不接力。
6. 集合竞价与POV：选股、竞价挂价和POV拆单逻辑不变，只调整总目标金额和
   开仓前置门禁。

## 二、统一定仓公式

```text
允许开仓的前提 = 券商无本系统旧策略仓

目标金额 = min(
    总资产 × 82.5%,
    总资产 × 85%,
    实时可用现金 - 现金缓冲,
    信号日成交额 × 退出容量上限,
    固定单笔金额上限（配置大于0时）
)
```

委托股数仍向下取整到交易所允许的整手，并在集合竞价提交前按真实委托价再次
核对冻结资金。这样不会因为多一手或手续费缓冲不足形成废单。

## 三、两层防线

- 计划层：A/C/E2/L/D看到任何旧策略仓，都不生成新买入；到期卖单照常保留。
- 执行层：09:20竞价、09:24 E2、09:30补单、POV恢复线程、E2延迟重试和D直连
  下单前都重新读取券商持仓。即使缓存中残留旧版买单，也会被拦截。

## 四、回归验证要点

- 空仓、总资产100万元、现金充足：参考价10元时目标金额不超过82.5万元，向下整手。
- 新单金额82.6万元：总仓位校验拒绝；85.1万元同时触发85%单票硬顶。
- 今日到期A/C/E2/L仓仍在：只有卖出计划，不出现BUY，D监控不启动。
- D接力：09:23卖出确认前无BUY；券商持仓为零并重新生成计划后才允许A/C/E2。
- 打新债券、打新股票或人工仓：不作为策略旧仓阻断，但可用现金仍按QMT实时值计算。
- 当日竞价部分成交：允许POV继续完成同一笔，不误判成旧仓。

## 五、风险说明

82.5%与取消衔接是新的实盘执行选择，历史8302x/5604x等包含不同衔接口径，
不能直接当作新规则的收益结论。扩大实盘资金前仍应先以小资金观察成交、滑点、
最大回撤和连续亏损，再决定是否提高资金规模。
