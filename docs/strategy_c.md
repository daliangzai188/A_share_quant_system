# 策略C：强势龙头两分支OR正式版

最后更新：2026-08-24
正式版本：`C_LEADER_UNION_20260630_V1`
生效日期：2026-08-25

## 一、策略定位

C是A>C>E>D单账户组合中排在A之后、E和D之前的强势龙头腿，核心思想是把市场
强势环境、强势板型与龙头地位结合起来。每个交易日都独立计算C候选用于审计；
正式生产仍保留“A无正式候选才由C补位”的依赖，C一旦形成计划就优先于E，
A/C/E三腿均无计划时才允许D启动盘中路径。

C不是“所有历史高收益条件的大并集”。正式版只冻结两条经过严格回放的可解释
分支，每条分支内部全部条件同时成立，两条分支之间满足任意一条即可：

```text
(分支A全部成立) OR (分支B全部成立)
```

## 二、正式入选条件

### 分支A：现有C核心精修

```text
market_chain_count_bucket       = 15_30
segment_limit_up_count_bucket   = 40_80
first_time_detail_bucket        = 1100_1330
board_type                      = multi_open
```

含义：全市场和所属市场分段均有较强接力氛围，但只保留11:00～13:30首次封板、
日内多次开板后仍能收住的强势承接样本。

### 分支B：强势龙头

```text
limit_up_count_bucket           = 50_80
market_leader_rank_bucket       = rank_4_10
fd_ratio_bucket                 = 0_1pct_0_3pct
```

含义：全市场涨停数量处于50～80只的活跃区间，个股按板高、首次封板时点、炸板次数
和成交额形成的信号日龙头排名位于第4～10名，同时封单/流通市值比为0.1%～0.3%。

## 三、排序、风险过滤和退出

两条分支合并后统一执行：

```text
1. 先应用C自身风险过滤；
2. 被过滤的股票剔除，允许同日下一名递补；
3. profit_source_score 降序；
4. turnover_rate 降序；
5. T+1开盘按既有滑点和成交规则买入；
6. T+3收盘卖出，跌停无法卖出时按原规则顺延。
```

C继续沿用原风险规则：封单/流通市值偏高、`LOSS_OVERLAY_WATCH`以及按连板高度
分档的炸板次数上限。82.5%仓位、费用、滑点、涨跌停和T+1均未改变；当前组合
资金顺序已在2026-08-24按用户决定单独调整为A>C>E>D。
