# 策略 N v4：第一分支量比后门禁 + 补充分支

> 状态：按用户提出的“N单腿机械复利严格大于2倍、胜率严格大于60%”目标升级。
> 正式优先级为`D>A>E>C>N`；N只使用前四腿均未占用后的单账户空闲资金。

## 一、规则与无前视边界

N只读取T日收盘后已存在的涨停池、严格as-of成交空间代理、市场状态和量比桶。
历史`fill_probability`是成交空间代理，不是校准后的真实成交概率；当日换手率必须在
当日候选打分完成后才进入后续训练集。

```text
共同底线：非ST、strategy_compatible、allow_buy_reliable、
          is_fill_score_reliable、fill_probability >= 60%

第一分支原始条件：
  segment_limit_max_height_bucket = 1
  segment_retreat_state_bucket ∈ {retreat_weak, retreat_2day}
  first_time_minutes升序 → circ_mv升序 → ts_code升序锁定每日第一名

第一分支v4后门禁：
  volume_ratio_bucket ∈ {4_8, lt_1}
  后门禁在第一名锁定后执行；失败整日放弃，不回补第二名，也不转补充分支

补充分支：仅当第一分支原始候选为空时启用
  market_chain_count_bucket = 3_8
  market_emotion_state_bucket = mixed
  amount降序 → circ_mv升序 → ts_code升序取第一名

执行：T+1固定开盘买入；T+2计划退出日可按实盘冲板止盈，否则收盘卖；
     跌停/停牌顺延到可卖日，目标仓位82.5%
```

真实订单仍经过账户空仓、现金、85%单票硬顶、停牌、涨停不可买、重复委托、实时
行情和统一订单网关检查。v4没有改变已有持仓的卖出、撤单、POV或收盘看门狗链路。

## 二、优化结果

冻结研究窗口为2024-05-20～2026-05-14，共481个信号日。v4得到75个候选日，
其中73个按固定开盘规则可买、2个开盘封涨停不可买；统一账户时间线实际入选24笔。

| 指标 | N v3 | N v4 | 当前完整组合 |
|---|---:|---:|---:|
| 样本数 | 32 | 24 | 166 |
| 胜率 | 59.38% | **75.00%** | 68.07% |
| 平均账户收益 | +1.3235% | **+3.4936%** | +5.9172% |
| 中位数账户收益 | +1.1044% | **+2.2067%** | +3.0789% |
| 逐笔机械复利 | 1.432724倍 | **2.197548倍** | 5971.386963倍 |
| 最大回撤 | -20.6996% | **-5.2008%** | -22.3862% |
| 最大盈利 | +14.6886% | +14.6886% | +52.4368% |
| 最大亏损 | -9.0586% | **-6.0955%** | -13.8239% |
| 盈亏比 | — | 1.6427 | 2.5995 |
| 最大连续亏损 | 3 | **1** | 4 |

v4同时满足用户设定的两个严格门槛：`2.197548 > 2.0`、`75% > 60%`。完整组合
机械复利由v3的5813.315346倍提高到5971.386963倍，最大回撤没有恶化。机械复利
是假设按同一账户收益序列连续放大的历史回归指标，不代表未来收益或资金容量。

## 三、分段验证与限制

| 分段 | N笔数 | N胜率 | N自身复利 | 含N/不含N组合 |
|---|---:|---:|---:|---:|
| TRAIN 20240520～20250723 | 14 | 78.57% | 1.996952 | 1.925897 |
| VALIDATION 20250724～20251212 | 2 | 100.00% | 1.070216 | 1.084566 |
| TEST_OOS 20251215～20260514 | 8 | 62.50% | 1.028251 | **0.930732** |
| 新增前向 20260515～20260626 | 2 | 100.00% | 1.116872 | 无完整组合对照 |

最后测试段的N自身已经转正且胜率高于60%，也优于v3的0.950722倍/55.56%；但加入N
后的测试段完整组合仍低于不含N组合，最大回撤为-13.6760%，不含N为-10.4367%。
因此严格样本外组合非劣门禁仍未通过。新增前向只有2笔，不能证明长期稳定。

本次比较已经查看过历史测试段，存在模型选择污染风险。v4只能继续小资金前向验证，
达到至少20笔真实完整平仓样本后再复审；资金容量未认证前不得依据机械复利扩资。

## 四、唯一规则源与复现

- `config/config.json`：v4参数、目标、风险披露和候选账本路径。
- `src/strategy_n.py`：唯一候选筛选、排序和排名后量比门禁实现。
- `scripts/build_strategy_n_backtest_pool.py`：重建75日v4候选账本。
- `scripts/research_strategy_n_v4.py`：候选门禁、分段和新增前向审计。
- `scripts/run_strategy_n_signal.py`：每日信号、资金占用门和不递补逻辑。
- `scripts/certify_current_executable_portfolio.py`：六腿统一账户认证，并硬性检查N复利和胜率目标。
- `scripts/strategy_health_monitor.py`：只统计券商真实完整平仓，不读取候选收益。

```bash
python3 scripts/build_strategy_n_backtest_pool.py
python3 scripts/research_strategy_n_v4.py
python3 scripts/certify_current_executable_portfolio.py --refresh-input-manifest
python3 scripts/verify_live_engine_matches_certify.py
python3 -m unittest tests.test_strategy_n tests.test_current_portfolio_alignment
```

验证必须得到75个候选日（73可买、2不可买）、组合N=24、总交易166笔、N复利
2.197548倍、N胜率75%、组合5971.386963倍和最大回撤-22.3862%。认证文件、代码、
配置或输入哈希任一不一致时，只拒绝真实新增BUY；已有持仓SELL链路必须继续运行。
