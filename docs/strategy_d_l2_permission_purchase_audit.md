# 策略D历史L2权限与采购验收

最后更新：2026-08-22

## 一、结论

当前权限不足，策略D的“完整首板触板事件账本 + 第一次可交易回封 + FIFO排队
成交 + 14:55撤余单”还不能进入正式收益认证。

这不等于现在就应该付款。当前最合理的顺序是：

1. 先向现有国金/QMT或掘金商务申请历史L2试用；
2. 要求沪、深、京三市场样本按本文件门禁验收；
3. 试用不满足时，再向三家官方行情管理方分别询价；
4. 三市场样本全部通过后才比较含税总价并购买。

单买上海数据不能完成正式D认证，因为D的股票池和盘中情绪口径同时覆盖
沪市、深市和北交所。任何供应商如果只提供成交明细、分钟K或周期快照，也不
足以重建虚拟涨停排队单。

## 三、官方产品核查

### 3.1 上海市场

上证信息官方历史产品说明可确认Level-2包含快照类、竞价逐笔类和K线数据；
Level-2产品还提供十档及最优价前50笔委托队列。公开价目为人民币12万元/年。
由于本项目24个月跨越2024、2025、2026三个自然年，不能自行把网页单价直接
当成最终总价，必须要求对方书面确认计年方式、含税总价和实际交付文件。

- [上交所历史数据](https://www.sseinfo.com/services/assortment/historical/)
- [上交所Level-2](https://www.sseinfo.com/services/assortment/level2/)
- [上交所公开价目](https://www.sseinfo.com/services/cpfwjg/)

结论：是上海市场的官方候选来源，但仍须用样本确认竞价逐笔文件如何映射
``ORDER_ADD/ORDER_CANCEL/TRADE``以及历史队列快照频率。

### 3.2 深圳市场

深圳证券信息有限公司官方说明明确：历史增强行情从2008年起提供，支持数据
本地落盘，字段包含逐笔委托、逐笔成交、3秒快照和证券委托队列，覆盖深圳
主板和创业板。这与D严格重放的字段需求高度吻合。

公开页面未给出本项目窗口的确定总价，需联系数据营销部询价：

- 邮箱：``szsi_marketdata@szse.cn``
- 电话：``0755-81902456``
- [深交所历史增强行情说明](https://www.szsi.cn/cpfw/fwsq/hq/yw-2.htm)
- [深证信息联系方式](https://www.szsi.cn/cpfw/fwsq/hq/lxfs.htm)

结论：是深圳市场的官方候选来源；先要样本和书面总价，不先付款。

### 3.3 北交所股票

官方公开页面当前可以确认的是北交所/全国股转系统Level-1许可管理；本次没有
从官方公开页确认覆盖两年北交所股票的逐笔委托、逐笔成交、委托队列历史产品
及价格。因此不能默认上交所、深交所或某个券商L2套餐自动包含北交所。

应向中证股转科技明确询问“北交所股票历史逐笔数据”，不要只写“北交所行情”：

- 邮箱：``hangqing@neeq.com.cn``
- 电话：``400-626-3333``
- [北交所境内行情授权指南](https://www.bse.cn/application/guide.html)
- [全国股转系统行情服务与联系方式](https://www.neeq.com.cn/services/invest_service.html)

结论：这是当前采购链最大的未决项。若无法取得北交所严格数据，正式D仍不能
通过现行三市场门禁；静默删除北交所会改变正式策略口径，本项不允许这样做。

## 四、付款前样本硬门槛

供应商至少提供2024-07-01、2025-06-30、2026-06-29三个时间点的沪、深、京
样本。优先要求每个市场各一份完整交易所日文件，而不是只给几行截图。

每份样本必须证明：

1. 全市场同步快照从09:30前开始并至少覆盖14:55；
2. 逐笔委托区分新增和撤单；
3. 逐笔成交保留买卖委托编号或可验证的订单关联；
4. 保留交易所/频道原始sequence，可检查重复与断档；
5. 有买一总量、委托总笔数和最优价前50笔队列量；
6. 价格为未复权原始价格，数量单位为股，时间至少精确到秒；
7. 能映射仓库标准事件并重放第一次可交易回封、FIFO成交及14:55撤单；
8. 能在同一时刻重建全市场封板情绪和D候选排序。

任何一市场失败都不付款。供应商演示“能查某只股票某一天”不等于通过，因为
正式研究需要484日全市场批量数据。

## 五、合同与交付硬条件

合同或订单必须书面列明：

1. 覆盖2024-07-01至2026-06-30全部484个交易日；
2. 覆盖沪市主板、科创板、深市主板、创业板和北交所全部股票，含窗口内退市股；
3. 允许内部策略研究、严格回测和本地长期存储；
4. 提供全量批量下载或日文件，不接受无法在合理时间取完的逐票限频接口；
5. 写清历史留存、字段、单位、复权、缺失日、纠错和补发机制；
6. 写清含税总价、授权主体、使用期限、交付方式和后续每日增量费用。
