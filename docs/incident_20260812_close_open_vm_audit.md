## 三、修复后的执行闭环

### 平仓

`到期识别 → 14:55快速提交 → 本地未关账则保持交易优先暂停并通知 → 14:56核查连续竞价覆盖
→ 14:56:20撤单交接 → 14:57/14:59按券商真实余仓兜底 → 15:00:30双快照和系统成交账对账
→ 有余仓则通知、次日按逾期仓优先清理`。

涨停、跌停、停牌、无买盘或券商拒单仍可能导致无法成交；系统能保证的是不静默、不盲目
超卖、持续按真实余仓兜底，不能保证交易所一定成交。

### 开仓

`08:50计划通知 → 09:00组合缓存 → 09:20复核/预挂 → 09:25后禁止伪竞价单
→ 09:26成交同步 → 09:30确认/补买/POV → 09:35成交核查`。

重启恢复口径：

- 09:20前：补计划和通知；
- 09:20-09:25：补复核和竞价预挂；
- 09:25-09:30：等09:30，不在静默段盲发；
- 09:30-09:35：恢复开盘确认/补单；
- 09:35后：只确认遗留在途单，不新建过期A/C/N普通买单；E按原延迟规则、D按盘中兜底规则；
- 错过窗口且无成交/在途单：主动通知。
